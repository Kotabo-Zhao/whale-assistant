# 鲸鱼娘个人助手设计与路线图

目标设备为荣耀 Magic6，免 root。助手以悬浮气泡为主要入口，重要事项使用通知。现有无障碍、Shizuku 与 Harness 连接继续沿用；安卓系统和目标应用权限是能力边界，不能保证后台常驻或读取其他应用私有数据。

## 现状

已有通知监听及有限规则过滤、应用使用统计、桌面形象、基础长期记忆、设备能力状态和内置市场。市场、Shizuku、自动化、记忆迁移和后台运行均未在目标设备验收。现有通知数据本地保留最多 50 条、7 天，记忆保存在应用私有存储；不会自动把通知输入模型。

## 分阶段方案和验收

1. **连接诊断**：在既有设备能力报告中针对未安装、未启动、未授权、未连接分别说明下一步；配对和启动的区别必须清楚。验收：各状态的界面测试；Magic6 上分别验证无线调试、授权和重启恢复。
2. **本地通知与简报**：对已收集通知使用可解释的本地规则分类，提供当前简报、分类及原始来源；空结果提示不能被理解为没有重要事项。默认不联网、不自动推送，规则可能漏判。验收：分类优先级、空值和敏感信息测试；通知权限、不同应用内容在真机测试。
3. **长期记忆管理**：新记忆记录写入时间和来源，旧记录标记为来源未知；允许查看与删除。未来扩展可编辑、导出和来源管理；不要对旧数据做破坏性迁移。验收：新旧数据兼容、存取和删除测试；真机升级前备份并验证。
4. **任务和提醒**：持久化任务、状态和重试记录；区分普通延迟任务与用户要求的准时提醒，系统权限和省电条件不足时显示失败。定期任务不能承诺精确或持续执行。验收：重启、取消、重复执行、时区调整和省电模式下的设备测试。
5. **语音交互**：先提供明确触发的语音识别与语音播报，再考虑可选唤醒；麦克风访问、网络和耗电透明显示。验收：识别取消、无服务、授权拒绝和退出后资源释放。
6. **手机任务闭环**：记录计划、执行、观察、失败原因及确认；高风险操作需用户明确确认，页面和通知文本不得作为系统指令。验收：可中止、失败不报告成功、真实应用逐项验证。
7. **后续能力**：插件兼容性与来源、用户确认的习惯建议、知识库、模型选择及设备诊断；每项先确认数据来源、权限及授权范围。

## 数据与权限

通知、使用数据和记忆默认留在本机；启用不同采集源须分别授权。只有用户主动选择提供的数据才可送给已选模型服务；界面说明外部处理范围。系统可能屏蔽验证码、密码、支付页与其他应用私有数据；简单规则无法确保识别全部敏感内容。插件安装前展示来源和权限，系统安装器与 Shizuku 必须分别授权。

## 实施记录

首批代码加入 Shizuku 未启动提示、本地规则分类的通知简报、按已出现的应用排除后续通知采集，以及新记忆来源展示；旧记忆无需迁移并显示来源未知。已有通知不会因排除应用而删除。通知简报不是天气或日历日报，不会自动推送或调用模型。

设备能力页面测试与 TypeScript 检查通过。当前机器未找到 Android SDK，Android 编译和 Kotlin 测试尚未完成；本批代码尚未打包或在手机运行。任务调度、完整日报、语音和跨应用闭环仍待实现，不能将设计或界面入口宣传为完成的自动能力。
