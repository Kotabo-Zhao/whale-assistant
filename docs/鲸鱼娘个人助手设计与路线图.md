# 鲸鱼娘个人助手设计与路线图

详细功能与技术设计见 [鲸鱼娘个人助手详细设计](鲸鱼娘个人助手详细设计.md)。

目标设备为荣耀 Magic6，免 root。助手以悬浮气泡为主要入口，重要事项使用通知。现有无障碍、Shizuku 与 Harness 连接继续沿用；安卓系统和目标应用权限是能力边界，不能保证后台常驻或读取其他应用私有数据。

## 现状

已有通知监听及有限规则过滤、应用使用统计、桌面形象、基础长期记忆、设备能力状态和内置市场。市场、Shizuku、自动化、记忆迁移和后台运行均未在目标设备验收。现有通知数据本地保留最多 50 条、7 天，记忆保存在应用私有存储；不会自动把通知输入模型。

## 分阶段方案和验收

1. **连接诊断**：在既有设备能力报告中针对未安装、未启动、未授权、未连接分别说明下一步；配对和启动的区别必须清楚。验收：各状态的界面测试；Magic6 上分别验证无线调试、授权和重启恢复。
2. **本地通知与简报**：对已收集通知使用可解释的本地规则分类，提供当前简报、分类及原始来源；空结果提示不能被理解为没有重要事项。默认不联网、不自动推送，规则可能漏判。验收：分类优先级、空值和敏感信息测试；通知权限、不同应用内容在真机测试。
3. **长期记忆管理**：新记忆记录写入时间和来源，旧记录标记为来源未知；允许查看与删除。未来扩展可编辑、导出和来源管理；不要对旧数据做破坏性迁移。验收：新旧数据兼容、存取和删除测试；真机升级前备份并验证。
4. **任务和提醒**：持久化任务、状态和重试记录；区分普通延迟任务与用户要求的准时提醒，系统权限和省电条件不足时显示失败。定期任务不能承诺精确或持续执行。验收：重启、取消、重复执行、时区调整和省电模式下的设备测试。
5. **语音交互**：先提供明确触发的语音识别与语音播报，再考虑可选唤醒；麦克风访问、网络和耗电透明显示。验收：识别取消、无服务、授权拒绝和退出后资源释放。
6. **手机任务闭环**：记录计划、执行、观察、失败原因及确认；高风险操作需用户明确确认，页面和通知文本不得作为系统指令。验收：可中止、失败不报告成功、真实应用逐项验证。
7. **后续能力**：插件兼容性与来源、用户确认的习惯建议、知识库、模型选择及设备诊断；每项先确认数据来源、权限及授权范围。

## 数据与权限

通知、使用数据和记忆默认留在本机；启用不同采集源须分别授权。只有用户主动选择提供的数据才可送给已选模型服务；界面说明外部处理范围。系统可能屏蔽验证码、密码、支付页与其他应用私有数据；简单规则无法确保识别全部敏感内容。插件安装前展示来源和权限，系统安装器与 Shizuku 必须分别授权。

## 实施记录

首批代码加入 Shizuku 未启动提示、本地规则分类的通知简报、按已出现的应用排除后续通知采集，以及新记忆来源展示；旧记忆无需迁移并显示来源未知。已有通知不会因排除应用而删除。通知简报不是天气或日历日报，不会自动推送或调用模型。

## 2026-10-29 开发记录

已安装 Android SDK 35、NDK 27.1、CMake 3.22.1 和构建工具；构建环境位于本机交付目录，不提交到仓库。新增手动创建、删除和恢复一次性提醒（系统可能延迟，错过提醒不自动补发），系统语音识别结果需用户确认后自行复制到对话；记忆可编辑；被排除的通知不再触发气泡。通知简报可显示最近三条本地记录及来源，不包含日历和天气。

应用插件管理器对非核心共享依赖版本冲突保留事务内私有副本，不覆盖运行时；核心单例的保护仍保留。此改动不自动覆盖 dshmarket 自身的安装流程，不保证插件兼容。

前端构建、插件管理器 71 项测试、设备桥 46 项测试及选定 Android 单元测试通过；调试版 APK 完成签名、对齐及内置环境校验。荣耀 Magic6 的覆盖安装、提醒触达、重启恢复、语音服务、插件安装及功耗均未测试。统一 Harness 对话容器、市场安装入口接入适配器、模型主动对话、完整日报、自然语言提醒、持续唤醒、任务执行闭环等仍未实现。

## 应用内手机插件目录

插件管理页新增按需加载的社区目录，使用 dshmarket 的公开目录来源，筛选合法 npm 包名；安装按钮调用应用现有的受控导入器，沿用版本筛选、安装脚本禁用和依赖隔离。只展示前 30 条搜索结果，目录下载上限 16 MiB，明确提示第三方插件可能不兼容。此入口与 dshmarket 自己的安装按钮是不同路径，后者尚未改造。目录、真实安装和 Android 兼容性尚未在荣耀 Magic6 上验证。

## 统一对话容器准备

将现有 Harness WebView 的安全设置、同源/资源拦截客户端和渲染进程恢复回调从独立 Activity 中拆出，允许后续由主界面和悬浮窗口复用。安卓应用在满足运行时、凭据和引导条件时自动打开对话一次；对话页提供鲸鱼娘与管理设置入口。当前对话仍为独立 Activity，并非真正嵌入主界面；自动进入和导航均尚未在 Magic6 验证。

进一步将用户手势触发的 OAuth 弹窗和文件选择桥提取为可复用组件。弹窗禁用脚本与文件访问，并阻断网络加载和 HTTP 认证；设备验证仍待完成。

后续代码已在 `MainActivity` 内加入独立的受限 Harness WebView，复用同源拦截、授权、文件选择和主题桥；设置入口隐藏对话而不销毁，返回操作先处理对话历史。原独立 Activity 保留为创建容器失败时的回退，常驻通知根据当前授权所有者选择入口。以上为代码及电脑端测试结果，不等于 Magic6 上完成对话、上传、OAuth 或生命周期验收；主界面仍需真机测试。

## 对话中的一次性提醒

新增 `mobile_reminder_list/create/delete` 和受认证的原生提醒桥。模型先读取设备时间与时区，再提交明确的设备当地日期、时间和读取到的时区，由安卓计算时间戳；设备时区变化、夏令时不存在或重复的时间被拒绝。通知权限未启用、输入无效或调度失败时返回错误，不能声称已安排。调度采用系统非精确闹钟，可能延迟；列表内容为不可信用户数据。仅支持一次性提醒，重复规则、通知重要性判断及对话层实际识别效果仍未验证。

工具需随 `0.3.9-whale-reminder1` 内置运行环境发布。它从 `0.3.8-whale-market1` 逐项复制，仅替换设备插件和版本元数据；`build-companion-reminder-runtime.py` 校验输入摘要、`verify-companion-reminder-runtime.py` 校验其余条目。更新运行环境前需备份不在保留名单内的自定义内容。此版本和提醒触达尚未在荣耀 Magic6 上测试。

## 对话语音输入

主界面对话新增按按钮触发的系统语音识别，识别结果必须由用户核对，确认后才尝试追加到当前对话草稿，不会自动发送；页面变化、会话失效、编辑器不可用时不插入。失败时可以由用户选择复制结果。识别服务可能联网；此功能不是常驻唤醒或语音播报。已在电脑测试注入脚本的目标选择与数据转义、通过 Kotlin 编译；Lexical 编辑器的真实输入行为和语音服务尚未在 Magic6 验证。独立 Activity 回退页面暂不显示该按钮。

## 手动朗读助手回复

主界面的朗读按钮优先使用用户选中的助手文字，否则尝试读取最近一条可识别的完整助手回复；用户核对预览后才开始，最长 2000 字，可随时停止，切换页面或进入后台也会停止。系统语音服务可能联网；独立 Activity 回退页面暂不提供朗读。网页结构变化或回复尚在生成时可能无法自动提取，用户可选中文字再试。真实语音服务、界面布局和 Magic6 后台行为尚未验证。

## 免打扰时段

可在助手设置中启用并设置开始、结束时间，按手机当前时区判断，支持跨午夜；相同时间表示空时段。时段内抑制桌面气泡、休息提示及低电量通知，不影响通知采集或用户设置的事项提醒通知。已跳过的通知气泡不会补发；休息与电量状态将在正常周期重新检查。时段边界已加入单元测试，实际后台运行和 Magic6 系统行为仍需真机验证。

## 插件依赖检查

移动安装器在切换链接前检查整个暂存依赖树的原生扩展文件和构建声明；发现扩展或无法完整检查时终止事务并保留旧版本。仅校验下载后的文件和声明，不能证明插件支持安卓、拥有合适权限或能够正常运行；第三方插件仍需逐个验证。检查设置了深度和数量上限，超限或不受支持的链接会拒绝安装。

## 手机目录安装确认

手机目录选择安装后先展示插件名、npm 包名、来源与权限/兼容性未知提示；用户确认后才交给移动插件管理器。运行环境处于锁定状态时不能确认；目录刷新会取消待确认项。此入口与 dshmarket 自身的安装按钮仍是不同路径；后者使用目录 URL 和自己的服务端安装流程，尚未接入手机事务安装器。

## 管理页面按需加载

将插件管理、文件管理和运行环境版本页面改为首次进入时加载，并展示加载状态。2026-10-29 同一构建环境对比：入口 JS 从 717,636 降至 636,411 字节，gzip 从 213,190 降至 192,587 字节；入口 CSS 从 89,565 降至 79,158 字节。分块校验检查页面没有被首屏 HTML 或入口静态导入。这里衡量的是构建文件大小，不是荣耀 Magic6 的启动或响应时间；首次进入这些页面仍需加载对应资源。

## 通知重复投递与授权状态

通知监听器对同一个系统通知标识、完整标题和正文的相同内容，在十分钟内抑制重复记录和重复气泡；内容变化、不同通知或超过时限的投递仍会记录。只在本地记录标识和内容的 SHA-256 摘要用于比较，旧记录没有摘要时不会参与去重；清空记录会一并清除摘要。设置页显示系统授权是否授予，但授权不代表监听服务一定在线。实际系统投递及后台限制尚待荣耀 Magic6 验证。

## 长期记忆导出

助手设置允许通过系统文件选择器导出版本化 UTF-8 JSON，包含全部记忆及来源。读取或校验失败时不打开目标输出；导出不改变原记忆，写入失败可能留下不完整目标文件。导出文件未加密，外部保存位置可能同步或被其他应用访问；当前不能导入恢复。编码与空数据已单元测试，系统选择器、云端提供方和荣耀 Magic6 尚未真机验证。

## 长期记忆导入

可通过系统文件选择器读取导出的版本 1 JSON；限制 256,000 字节、最多 100 条，严格校验 UTF-8、ID、长度和敏感内容规则。导入前列出全部待新增内容，用户确认后以原子方式合并；相同 ID 或相同文本跳过，已有记忆不覆盖。核对期间原记忆发生变化时拒绝写入并要求重新核对。未知字段不会导入，敏感规则可能漏判，文件可能来自不可信来源。格式与合并规则已单元测试，实际文件选择、写入和设备升级仍待 Magic6 验证。

## 记忆文件操作线程

系统文件提供方的读取、导出写入与确认后的合并改在后台线程执行；同一页面同一时刻只处理一个记忆文件任务，并显示提示。页面销毁后不再展示旧页面的结果；已确认的写入可能继续完成。慢速或无响应的第三方文件提供方仍可能让本次操作长时间等待，Android 端实际行为尚未在荣耀 Magic6 验证。

## 通知记录损坏保护

本地通知记录读取时校验大小、条目数与必要字段；解析失败时保留原记录，不把损坏当成空列表，也不继续写入新通知。设置页提示读取失败，用户明确确认后才可清空记录。模型记忆写入目前依赖工具提示限制，并非原生确认或候选审批，自动推断记忆仍需补齐用户确认流程。损坏数据检测与构建已测试，实际升级和系统监听器行为仍待真机验证。

## 候选长期记忆

助手记忆工具提出的新条目会以待确认状态保存；它们不出现在模型记忆检索中，用户可在助手设置的长期记忆列表里逐条确认或删除。旧数据无状态字段时沿用已确认状态；备份导入保留待确认状态。工具返回 pending 标志，配套运行环境 0.3.10 提示模型不得将待确认条目描述为已记住。旧运行环境的提示不具备这个说明，升级后需要在应用内更新运行环境。模型可能忽略提示，实际对话、确认 UI 和运行环境升级尚未在荣耀 Magic6 验证；自动从通知提取候选仍未实现。

## 候选记忆提示

助手新建待确认记忆后，若悬浮助手正在运行且可显示，会出现不含记忆正文的提示；重复提交现有条目不会再次触发。气泡遵守既有免打扰、锁屏、屏幕状态和频率限制，不保证送达；设置页显示待确认条数。检索返回的总数只统计已确认记忆。候选判断规则和 Android 构建已测试，实际气泡与设备后台行为仍待 Magic6 验证。

## 跨应用任务步骤顺序

任务台账现在要求所有前序步骤都确认成功才能放行后续步骤；前一步结果不确定时提示核查，可重试失败时先处理该步。回执未明确提供验证结果时不再默认验证成功；同时修正了回执中尝试次数的显示。台账单测覆盖上述情况；它仍不直接执行动作，也不能独立证明模型报告的验证结果真实，完整观察、动作和核验闭环与荣耀 Magic6 真机测试仍未完成。

## 窗口变化的设备侧核验

任务步骤选择 windowChanged 时，除了调用方报告已核验，还要求该步骤开始后无障碍服务记录过成功动作，并且当前窗口结构指纹与步骤开始时不同；否则记为结果不确定，不放行后续步骤。指纹不包含文本，纯文本变化可能被保守地判为未验证；结构变化也可能由其他事件造成，不能证明目标任务已经完成。其他验证模式仍依赖调用方报告，完整的动作关联、端到端核验及 Magic6 真机测试仍未完成。

## 任务动作与证据关联

窗口变化核验的动作回执现在只接受当前进行中的同一任务、同一步骤和尝试，并要求实际无障碍动作的应用、动作类型、控件 ID 与计划一致；不匹配或过期的回执不能证明该步骤。目标必须与实际资源 ID 完全一致，否则结果会保守地保持不确定。结构变化仍可能由其他事件造成，其他核验模式和完整任务因果验证仍未实现；该检查与设备实际运行尚未在 Magic6 上验证。

## 目标控件消失核验

任务步骤使用 targetGone 时，要求匹配当前步骤的实际无障碍动作，并在当前可访问窗口中查询不到目标资源 ID；查询报错、动作不匹配或目标仍在时保持结果不确定。无障碍窗口不可见或应用未完整暴露节点时，查询不到并不等于业务操作已经成功，必须结合用户任务核验；Magic6 真机和第三方应用行为尚未验证。
