# 鲸鱼助手 0.3.8-preview.81

主人档案现在会在每轮对话自动加载。App、桌宠和主动跟进使用同一本机档案与秘书事项台账，换会话、换角色后仍能使用已确认的称呼和习惯。

- 增加称呼、语言、时区、城市、工作身份、沟通偏好、作息、设备、项目及有有效期的近期安排；支持确认、纠正和遗忘，冲突或过期的内容不会作为当前事实。
- 增加秘书事项的创建、下一步、等待对象、截止时间、提醒、改期、完成、取消和删除。重复请求不会创建第二条，过时版本不能覆盖新修改。
- 改期或关闭事项会停用旧提醒；完成会清除对应系统通知。恢复旧备份不会覆盖当前状态、恢复已删除事项或直接重新启用提醒。
- App 设置与桌宠会话菜单共用原生管理面板，桌宠可直接在原窗口编辑，两套主题共用设计样式。桌宠使用紧凑布局，保留聊天输入框。
- 档案和主动交办事项遵守长期记忆权限，秘书事项无需开放通知读取。完整主人档案不会自动发送给后台 Worker。
- 运行环境更新至 `0.3.85-whale-owner`，修复本机桥接成功回执的字段判定，保证新会话也能自动装入档案。

本版已在 Pocket S 使用真实模型验证跨会话称呼、纠正、遗忘，以及事项创建、改期、完成和 App／桌宠共享。详细记录见[主人档案与秘书验收](PocketS主人档案与秘书验收-20261106.md)，实现边界见[主人档案与秘书闭环](主人档案与秘书闭环-20261106.md)。

本版提供本机数据闭环；尚不包含跨设备同步或外部日历双向同步。提醒是否准时送达仍受 Android 后台和省电策略影响。
