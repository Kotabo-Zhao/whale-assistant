# 鲸鱼助手 0.3.8-preview.57

在「全部助手偏好 → 长期记忆」开启「让鲸鱼娘思考是否主动聊聊」，选择每天或每周最多一次。当桌宠可见、设备亮屏解锁且对话空闲时，鲸鱼娘可向已选后台模型询问此刻是否值得开口。初次可以只按时段问一个偏好；关联个人记忆需要开启长期记忆与桌宠记忆访问。每次最多使用一条已确认的简短记忆。免打扰、失去授权、原记忆删除或变化均会影响展示。模型可以保持安静；静默和请求失败均消耗本周期机会。偏好页显示最近一次判断状态。

模型只能生成一个问题。点击气泡进入桌宠对话，或在一天内自行打开桌宠查看错过的问题，直接输入回答即可携带提问上下文。该能力默认关闭，与原有本地模板搭话分别授权。

首次从欢迎页进入本地资料时直接打开编辑框。保存后按开头文字搜索，点击结果可重新查看。后台任务页把当前第一页中第一个可回答的问题及其输入框置于概况和筛选之前。

后台创作按命名预设实际解析出的沙箱能力判断，并在草稿操作前重新检查。原始自定义权限组合无法明确继承时，保留受阻工单。后台模型开始重试时，同一供应商的新工单短暂等候，原工单可继续重试。最近完成回合的详情显示已观测到的模型重试次数及供应商上报的 token 总量。未上报的用量不估算金额。以上 Worker 更新对应运行环境 `0.3.59-whale-task-budget`，已有安装可在应用内确认更新。

提供两份相同包名与签名的本地预览 APK。完整版内置离线运行环境。轻量版保留本地资料、向量与语音模型，首次需要运行环境时，点击安装并在系统文件选择器选取配套的 `whale-0-3-59-rootfs.bundle`。安装器使用 APK 内清单校验文件大小和 SHA-256。已有兼容环境可继续使用。构建轻量版使用 Gradle 参数 `-PwhaleSeparateRuntime=true`，输出独立于完整包。
