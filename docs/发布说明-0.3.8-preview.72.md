# 鲸鱼助手 0.3.8-preview.72

本版补充 App、对话、桌宠与工具的动效，并推进工单存储异常的隔离与人工恢复。

- 两套主题的浅色、深色外观使用统一的动效节奏，覆盖页面、弹层、控件、原生设置、桌宠新消息、内嵌工具、悬浮工具及受控标识。
- 跟随系统减少动态效果设置，保留键盘避让、导航和窗口尺寸的原有布局逻辑。
- 工单、目标账本增加带 SHA-256 校验的恢复副本。损坏记录进入待核对状态，健康工单继续加载；任务详情提供只读预览和明确解锁入口，解锁后仍需单独继续原工单。
- 实际写入失败时回滚内存对象及版本。目标恢复后清除旧核验结论，监督日志损坏后隔离异常记录并暂缓新的模型检查。
- 运行环境更新为 0.3.72-whale-resilience；任务数据保持本机。

Pocket S 已完成留数据升级、四主题 App / 主对话 / 原生页检查、桌宠键盘与内嵌工具、菜单及设备受控状态回归。真实模型工单完成“损坏隔离→健康工单独立完成→核对解锁→继续原工单”的完整链路。前端 1,155 项通过；脚本最终 477 项中 473 项通过、4 项跳过；Android 当时 1,844 项无失败、37 项跳过。竖屏手机高度的进一步调整随 preview.73 交付。设计记录见《App与桌宠动效设计-20261106》，容灾演进见《异常模拟与容灾设计-20261106》。
