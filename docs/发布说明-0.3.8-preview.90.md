# 鲸鱼助手 0.3.8-preview.90

修复桌宠里一条消息卡住，后面整列消息都发不出去的问题。已有后续消息时，前一条连续 30 秒没有进展会让出队列。也可以点输入框上方的“结束等待”立即继续。失败原文保留在“待处理消息”里，可以单独处理。同一话题里已接受的后续消息会按顺序继续，收起窗口或服务重建也能恢复。早期版本没有记录所属话题的待发消息仍可手动取回。

连接中断时，手动恢复使用原请求编号。主对话已明确判定失败时，只有用户重新发送才创建新编号。尚未确认的后台工单可以用原工单编号恢复。若主对话可能仍在执行原请求，桌宠会保留原会话入口，让后续消息在独立连接中继续，并保留当前话题、已完成的对话和 Worker 转述。迟到的回复不能覆盖后续消息。

输入法的“发送”和桌宠按钮现在使用同一提交入口。等待状态、重试和排队数量显示在输入框旁。意图分类遇到临时服务错误或返回无效格式时，普通对话可以继续，工具仍通过原有权限检查。模型推理在收到 HTTP 500、502、503、504 且尚未接收回复时，允许在原有时限内短暂等待并补试一次。已开始的流式回复和工具执行继续按原请求追踪。

AYANEO Pocket S 的最终安装包通过了 19 项真机回归。模拟队首无响应时，64 条后续消息在约 32 秒内处理完毕，队列已满时的输入草稿仍在。模拟主对话忽略取消时，后两条按顺序完成，原请求迟到也没有改写记录。真实模型通过桌宠窗口回答了测试问题，发送到重开窗口核对回复用时 10.3 秒。测试期间也实际观察到模型服务返回 HTTP 500 和 503。
