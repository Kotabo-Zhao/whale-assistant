## 会话连续性与记忆版本开发进展
- 桌宠会话复用条件改为资料/记忆授权及语义能力组合；资料或记忆内容本身改变不会打断 Harness 会话。会话重建时只传受限的旧消息摘录，保留最近六条全文、较早消息各 160 字摘要，总计最多 8,000 字。
- 主界面的会话工作区新增私有的用户组织层：可对真实 Harness 会话设置本地别名、分组、归档和批量归档/恢复；组织数据不复制对话正文或 Harness 原始标题，也不会承诺删除运行时会话。桌宠转入主对话仍使用同一个已登记 Harness 会话 ID；从主界面选择该 ID 可继续该对话。组织数据纳入全量备份，导入时仅合并本地注释。该新增链路尚未构建、测试或设备验证。
- Agent 纠正记忆改用检索结果的 `revision`，并可携带 `operationId` 重放同一修改；旧的 `expectedText` 路径仅为历史客户端兼容。成功纠正保留最近 20 个本地旧版本及其失效时刻，返回新的 revision 和历史数量；搜索结果只返回当前版本、来源、确认状态和历史数量。
- 记忆详情现在可在本机查看历史版本的内容、来源、确认状态与有效期；历史正文仍不会经 Agent 搜索或模型调用返回。按时间检索、冲突处理和完整历史管理仍未完成；本轮未运行验证，以上是待验收的实现状态。

## 回答来源卡片开发进展
- 桌宠从资料工具返回的稳定资料 ID、版本、文档/原件关联、分段位置和解析覆盖范围生成独立来源卡片；卡片不保存或展示工具返回的摘录正文，避免把不可信资料重复混入回答。
- 来源卡片与桌宠回复一起以兼容旧记录的 v2 本地历史格式保存；旧 v1 对话读取时不伪造引用。桌宠点击来源卡片会启动原生资料详情，并按资料 ID/版本重新核对；删除或版本变化时拒绝展示旧内容。详情可查看原件或把已核对资料带入对话。主界面对话卡片及跨入口的双向消息同步仍未完成。
- 已新增解析和旧历史兼容的测试源码，但遵从先开发后统一测试的要求，尚未执行。
