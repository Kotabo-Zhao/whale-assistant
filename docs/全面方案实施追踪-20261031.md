- 单条资料删除加入同库墓碑与 10 分钟撤销；撤销仅恢复记录，不恢复已抑制的派生记忆。近期删除入口说明原件和其他分段仍保留；单条删除不等于整份原件删除。

## 语义检索开发进展
- 增加单独授权的资料向量索引：使用已有 OpenAI 凭据、text-embedding-3-small 和 256 维向量；后台非计费网络分批处理，索引与查询分别限制每日请求次数。正文和查询会发给服务，默认关闭，界面明确说明。
- 本地向量缓存按资料 ID、文本版本和模型区分，后台入库前重新核对原文和授权；资料修改、删除、备份恢复与撤权触发缓存失效。新增词法/向量混合检索工具，按排名融合，结果仍需读原文核对。
- 当前只覆盖资料文本，不覆盖长期记忆、事项和多供应商嵌入；首次建立完整大库索引可能跨越多天。向量搜索仍为本地逐向量扫描，尚非大规模近似最近邻索引；语义召回质量、索引完整性、设备耗时及隐私竞态均未验收。普通词法检索保留。
- 本次实现依据 OpenAI Embeddings API 文档的输入与 dimensions 参数；未发起真实请求，未构建、测试或安装。
