# 鲸鱼助手 0.3.8-preview.80

后台做事时继续聊天，并让 Router 汇总状态、安排下一步和核验结果。

- 增加持久的协调台账、变化合并、前台空闲唤醒、最新状态校验和重要汇报送达，避免逐个 Worker 抢占对话。
- 手机操控交给独立 Worker，前台限制长等待。桌宠等待期间可另答独立问题、查资料和查询/请求停止后台任务。
- 新增有来源路径的关联召回及本地只读预取，支持版本与权限失效，限制跳数、内容量和并发资源。
- 修复创建工单时初始预算未传到执行记录的问题；新任务保留明确指定的预算，已有任务重试不自行增加预算。
- 纯屏幕任务可只携带 10 个必要工具，减少每轮重复上下文；完整设备工具集仍供需要文件和 shell 的任务使用。
- 延续上一版的面部表情、15 类手持道具、过渡动画及两套风格四种配色。
