# 桌宠独立动作重制

## 问题与调整

用户明确反馈 preview.82 动画异常，要求每个动作独立绘制。旧版虽然增加了手部约束和道具接触测试，仍把同一站姿拆成公共骨架，手臂、袖子、表情与道具的组合看起来生硬。旧版检查不构成视觉通过。

本次替换为 17 个业务状态加独立喝水动作，共 18 组完整角色逐帧原画。阅读、书写、喝水、手机点按各自拥有身体姿态、视线、手部和道具动作；取消网格变形、独立眼嘴贴片和悬浮道具层。AI 生成原画及修订提示词保留在 `art/pet-independent/`，运行时只播放整帧。

## 动作与节奏

- 阅读先停留，再抬手翻页、收手；书写改为坐姿笔记，包含抬头思考和眨眼。
- 喝水包含持杯、抬杯、杯沿接近嘴部、轻啜、放低；每 24 秒待机周期只播放一次 4.5 秒动作。
- 点手机包含指尖靠近、接触、离开与停顿；观察、等待、暂停、结束、异常有各自原画。
- 暂停、结束和异常只播放一次进入动作，后续保持尾段；不会重复举手或鞠躬。
- 接单、询问、回复等仍遵循业务优先级，接单后的回复顺序保留；异步解码的旧动作不能覆盖新状态。
- 状态切换采用完整姿态切换，不做骨骼变形或不同角色帧之间的形变补间。姿态切换接缝仍需在实机中看观感。

## 资源与耗电机制

- 一帧只做一次整图绘制；按下一帧边界唤醒，不保持 30/60 FPS 的空转计时器。
- 图集按需后台解码，最多缓存 3 张；在 264 像素桌宠尺寸下缓存上限约 9.38 MiB，另有最多一张在途解码。没有把全部 18 张图集常驻内存。
- 待机停留可睡眠秒级；省电模式将连续换帧间隔下限设为 200 ms，业务状态到期仍及时处理。
- 屏幕熄灭、锁屏、宿主遮挡和减少动态设置撤销动画回调；静态模式保持对应语义姿态。
- USB 连接时的 CPU 时间只能说明进程开销，不能换算电池续航提升。本轮离电长时耗电结论尚未测得。
