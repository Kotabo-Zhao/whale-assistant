# 鲸鱼助手 0.3.7

本版面向 Android 与 AYANEO Pocket S，桌宠对话是自然语言入口，后台任务、应用工具和本地资料使用统一的工作台。

## 对话与执行

- 说出需要的结果即可。模型判断适合后台进行的整理或工具创作，接受后在对话中显示工单名称。普通问题直接回答，后续输入可以继续编辑。需要自行指定模式时，可以从桌宠会话选项、长按菜单或后台任务页手动交办。
- 主会话和桌宠通过同一套 SuperAgent 工单引擎管理多个独立 Worker。队列处理依赖、优先级和设备互斥。追加信息、回答追问、继续和撤销均关联具体工单。自动提交中断后按原指令号恢复。Worker 继承派工会话的权限预设，按只读、创作或设备模式检查每次工具调用，并服从实际系统授权。
- 工具工坊可以生成应用内可运行的功能草稿。修改保留版本，用户在预览后选择是否启用。主工作台与桌宠可打开已启用的工具。

## 桌宠与设置

- 角色关节表现待机、接单、工作、等待和完成。聊天、收藏和交办使用鲸鱼娘原画头像、按状态区分的贴纸，以及浅色和深色配色。
- 主工作台聚合对话、资料、事项、工具和设置。助手偏好首页提供桌宠与权限、记忆与资料、通知与提醒、日常助手四个入口。具体设置与通知历史只在进入时加载。

## 本地资料

- 支持 Android 分享、文字选区、文件选择器、独立应用拖放及主动收藏剪贴板。一次性屏幕收藏由系统询问授权。保存后返回来源应用。
- 原件、解析状态和检索片段保存在本机。支持文本、图像文字识别、文件解析和音频转写。近期投放可直接回读，失败的解析可重试。资料用于模型对话仍受独立授权控制。

## 验收范围

本版提供 AYANEO 实测的调试签名安装包。微信、小红书正式客户端上的完整投放流程、离电续航和更深层原生功能创作仍在验收。详细记录见[持续开发日志](鲸鱼助手持续开发与真机日志-20261104.md)，代码路径与权限边界见[任务与记忆架构](鲸鱼助手任务创作与多模态记忆架构.md)。
