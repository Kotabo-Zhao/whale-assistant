# 鲸鱼助手 0.3.8-preview.75

本版继续缩短真实手机操作中的模型往返与步骤等待，重点处理“动作已经完成，模型却反复观察和返工”的问题。

## 屏幕连续导航

- 新增 `mobile_screen_sequence`：一次提交同一已知 App 内 1–6 个精确文字目标。每步读取新页面、重新定位、核实前台应用后点击，返回逐步回执及最终观察。
- 已知路径直接走连续导航，省去起始观察和每次点击后的云端决策；未知图标、跨 App、重要操作保留原有观察和单步流程。
- 前台应用通过 Shizuku 常驻服务读取，避免为每步创建 Shell 进程及耗尽 Shell 会话名额。
- 每步仅保留短暂渲染机会；目标未出现时有界重读，最后在本地比较观察文字稳定性，减少将转场画面交给模型后的额外截图。
- OCR 按实际视觉间距分离误合并的图标和文字，禁止猜测性删除前缀。仅按自有控制条的真实屏幕范围排除其 OCR 文本，并保留来源与范围，防止“暂停 / 停止”被误认为目标 App 的按钮。
- 目标缺失、歧义、前台 App 变化、暂停、取消或结果不确定时停止后续步骤。取消可先于排队请求到达；旧操作编号不能重用。动作已注入不代表业务成功，异常时不自动重放。

## 模型核验与收尾

- 清除重复的 OCR 全文与无用传输字段，保留观察坐标、租约和错误信息。
- 对已安装的 MIT 插件 `dsh-answer-reviewer` 0.7.6 提供精确源码哈希限定的加载兼容：评分仅读取当前最终回答、真实用户要求及同轮屏控证据，排除评分反馈自身和运行时注入。
- 评分证据保留部分完成、错误和不确定性；说明自有控制浮层的来源。不降低评分门槛、不关闭评分、不修改用户的模型选择或插件磁盘源码；不同上游源码保持原样。
