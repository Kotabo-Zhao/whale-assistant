# 鲸鱼助手 0.3.8-preview.91

修复主对话的一条失败消息阻塞后续队列：模型请求异常退出后，已接受的后续消息会重新唤醒执行。模型流连续无有效进展且存在排队消息时，30 秒后结束当前请求并继续后续消息；无后续消息时使用 180 秒无进展保护。有持续有效输出的回复不受总时长限制。迟到的数据不能写入后续回合，主动停止也不会触发自动续跑。

发送确认与附件同步分别增加 15 秒等待上限。连接异常、发送失败和确认超时都会退出等待状态，恢复可重试的草稿。未确认是否接受的请求在重试、切换投递模式或重开页面后仍使用原请求编号，避免重复执行。重连不再无限等待已取消的旧连接；本机回环连接不受浏览器错误的离线状态阻挡。

修复 AYANEO 旧版 WebView 缺少 AbortSignal.any 导致连接初始化失败、主对话一直停留在选择工作区的问题。兼容处理在连接模块工厂启动前完成。原生会话入口也会携带官方适配层可识别的会话片段。

验证：15 项队列与兼容性定向回归通过；前端 1142 项测试通过；脚本 522 项通过、4 项跳过；Android 单元测试 1858 项通过、37 项跳过。类型检查、ESLint 和质量门检查通过。Android Lint 未通过：8 个错误均位于本次未修改的富文本、知识包、快捷截图、桌宠输入框及原生布局文件，包含低版本 API 兼容、废弃调用与控件属性问题；未创建基线或隐藏这些错误。

AYANEO Pocket S 使用最终安装包完成真实主对话回归：故意让首次发送确认不返回，15 秒后草稿恢复；再次发送使用同一请求编号，Host 仅记录一条已接受消息，真实模型答案显示在主对话界面。此测试验证发送端异常恢复；模型队首卡住、旧连接忽略取消等故障使用实际运行时方法的隔离注入验证，不等同于实网服务故障验收。荣耀本轮未测试。
