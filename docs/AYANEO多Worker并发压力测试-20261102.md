# AYANEO 多 Worker 并发压力测试（2026-11-02）

测试使用 AYANEO Pocket S、真实 DeepSeek API 和启用的 dsh-answer-reviewer，每个只读任务计算同一个算式。CPU 为设备整体八核归一化占用率，每约 5 秒采样；内存为系统 MemAvailable。测试仅覆盖短时简单任务，运行结果受网络与模型服务波动影响。

| 请求任务数 | 实际同时活动峰值 | 结果 | 平均/最慢 Worker 耗时 |
|---|---:|---|---|
| 4 | 4 | 4/4 完成 | 5.1 / 6.1 秒 |
| 8 | 7 | 8/8 完成 | 11.2 / 29.1 秒 |
| 16 | 16、16 | 两轮各 16/16 完成；无 Worker 请求错误 | 6.1 / 7.7 秒；6.4 / 8.7 秒 |
| 32 | 31、32 | 前两轮各 32/32 完成，无 Worker 请求错误；第三轮主会话失败，测试中断，不能判为通过 | 前两轮平均 10.4、10.3 秒，最慢 32.3、32.6 秒 |
| 64 | 28 | 64/64 最终完成；18 个 Worker 共记录 90 次 DeepSeek 502，重试后恢复 | 平均 22.5 秒，P95 62.6 秒，最慢 83.7 秒 |

空闲采样的 CPU 均值约 3.0%，最低可用内存 5.22 GiB。两轮 16 任务测试 CPU 均值约 18.6%～18.8%，峰值约 25.1%～25.4%，最低可用内存 4.48～4.52 GiB；64 档 CPU 均值 15.7%、峰值 32.3%，最低可用内存 4.30 GiB。测试中电池温度采样最高 35.0°C。CPU 较低不能排除瞬时峰值或说明等待原因；HTTP 502 是服务返回，不能据此确定发生原因。

普通对话完整回复时间：空闲单次 3.523 秒；16 个该轮 Worker 活动时单次 4.288 秒。一次混合负载探针失败，该轮同时夹杂上一轮未收尾任务，不能作为纯 16 任务对照。这些是单次端到端耗时，不是首字时间或统计均值。

结论：16 是本次两轮干净完成、且普通对话探针成功的最高档位，可作本次条件下的保守参考；32 曾两轮成功，第三轮主会话失败，不能称稳定上限。64 个提交不代表 64 个同时运行，本次仅观察到 28 个同时活动，且出现大量重试。没有长期或高强度任务压力测试，不能给出绝对最大稳定数量。首轮请求 1 个实际派发 5 个，未用作单 Worker 基线。临时 API 凭据已移除，测试卡片与会话保留供追溯。

原始采样、设备测试日志和模型错误统计在 `build/worker-stress/`；机器可读摘要见同名 JSON。第三轮 32 测试失败后的部分任务状态在后续运行环境重启后变成中断，不能将其当成功或强行重放。
