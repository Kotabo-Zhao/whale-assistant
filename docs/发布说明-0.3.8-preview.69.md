# 鲸鱼助手 0.3.8-preview.69

2026 年 11 月 6 日，Android 预览版，内部版本 114。内置运行环境 0.3.68-whale-integrated。

- **对话与外观**　深海·专注、月汐·陪伴各有浅色和深色。主应用、对话输入区、桌宠、原生设置和受控状态条复用主题。对话与其他页面共用导航，横屏与竖屏均按 App 的布局定位。
- **桌宠工具**　在桌宠内打开已启用的 HTML 小工具，返回时保留工具状态与聊天草稿。结果可以带回对话，也可以手动保存到资料库。收起软键盘后恢复原窗口尺寸。
- **设置**　设置首页收拢为模型连接、桌宠与主动跟进、通知与免打扰、外观与语言、设备控制、运行与数据六组，完整设置从高级入口进入。
- **主动跟进**　对话或资料变化触发判断。关联事项回到原工单，新线索值得跟进时才发起对话，同一事项重复更新会去重。
- **设备控制**　优先读取原生控件树，可按区域识别图中文字并返回可点击的原图坐标。执行期间显示暂停、继续和停止。修复大截图经 Shizuku 返回时数据被截断的问题。
- **后台任务**　使用来源会话委派权限，创作任务使用专属目录。任务和目标分别记账，支持原协调会话核验结果。恢复已有子会话时使用原 ID，并重新检查来源权限。

保留数据安装 APK 后，在工作台点“更新运行环境”。更新会替换 Ubuntu 系统目录，手工 apt 安装的软件需重新安装。应用会先备份会话，尝试保留模型连接、附件、技能、插件和默认工作区。

真机数据、覆盖范围和待验项目见[逐项验收记录](整合开发与PocketS验收-20261105.md)。
