# 预览五十一：工具创作与日常使用界面

工具页把创造模式与已启用工具分为两层：上方集中“去对话创作”和“功能工坊”，下方用工具卡片直接打开已启用版本；工具较多时可按名称查找。主页的小工具区继续保持紧凑，不重复展开整套说明。界面沿用简约/可爱与明/暗主题。

读取等待、空列表和读取失败分别呈现；失败提供重试并保留上次工具。非法返回不再被静默吞掉。打开工具或进入创作时防止重复派发，打开失败提示不会因后台列表刷新而消失。创造入口只填写对话草稿，不自动提交模型请求。未增加定时轮询或新的后台服务。另调整窄屏资料卡，使正文与“更多操作”分行，减少阅读宽度被挤占。
