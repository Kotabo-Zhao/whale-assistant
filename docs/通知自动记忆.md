# 通知自动记忆

“自动记住其他应用通知”是单独开关，默认关闭。开启后还需要打开长期记忆、收集通知摘要以及授予 Android 通知读取权限。只处理开关启用后的新通知，不回填历史记录；排除的应用和私密通知不会被处理。

符合现有敏感内容过滤的新通知按来源应用合并为一条“未经核实”的记忆，每个应用保留最近 4 条不同的短摘要，无需逐条确认。应用内摘要自动更新；已有旧格式通知记忆不会自动迁移或删除。达到 100 条上限后，新来源无法加入，但已存在的来源仍可更新。记录可在长期记忆中查看、编辑、删除和导出。关闭采集不删除此前记录。

其他应用通知可能是别人写的内容，不能当作用户自述或可信指令。被模型检索时，相关文本可能发送给所选模型服务；现有敏感过滤不能识别所有隐私。此功能目前不读取应用私有数据库、不自动归纳多条信息为用户画像，也不保证从所有应用获取信息。

## 自动使用概览

另设“自动整理应用使用习惯”，默认关闭。需启用长期记忆、授予系统使用情况访问权限，并保持悬浮助手服务运行。服务约每六小时在后台读取系统最近七天的粗略前台使用统计，排除本应用和用户排除的应用，最多取五项并维护一条自动记忆；只更新自动记录，不覆盖用户手写记忆。若同时启用通知采集和自动通知记忆，概览会关联本机留存的通知数量。通知记录有数量与时间上限，因此计数不代表完整历史；统计可能不准确，不代表用户喜好。关闭开关不删除已有记忆；删除该概览后，如开关仍开启，后续统计可能重新生成。未授权、数据不可用或应用被系统暂停时不会伪造统计。
