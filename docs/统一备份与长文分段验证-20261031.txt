统一备份、长文分段与原子任务提交（2026-10-31）

已实现
1. 资料数据库写入不再受 100 条和旧 JSON 512 KB 限制；保留单段 8000 字边界。旧 JSON 导入继续严格校验旧格式，资料 JSON 备份扩至 32 MB。
2. 文本文档提取上限提升至 200 万字符，文本 PDF 最多 500 页；分段保存，记录 documentId/chunkIndex/chunkCount。Agent 可按 documentId 翻页浏览同一文档，再按 ID/版本读取。超过解析范围时有明确截取提示，原文件仍保留。扫描 PDF 仍最多识别前 3 页。
3. 分享文字、图片理解结果和文档片段统一交给持久后台队列；模型处理完成后的记忆、搜索索引、完成标记和任务删除在同一个 SQLite 事务提交。取消或恢复前的旧代次不能向恢复后的数据提交结果。
4. 资料来源增加 record_id 到 event_id 的映射，删除图片资料时也能阻止基于原图摘要的旧事实重新生成。
5. 修复模型摘要拼回原文被误当作用户编辑而删除派生记忆的问题；模型注释使用独立字段，文档处理不再重写原文。
6. 原生记忆管理增加导出统一备份、恢复统一备份及回退到上次恢复前入口。备份使用 SQLite 一致性快照并流式复制，最大 256 MiB；恢复验证表结构、数据库完整性、记忆/资料行与删除元数据，不执行备份里的 SQL。
7. 恢复保留现有授权，合并新旧删除保护，不重放旧任务；后台事项提醒禁用，需要用户重新核对。恢复前保存本机快照，可回退结构化资料和记忆。删除保护采用保守并集，在极端中断时可能多保留保护，不会因恢复旧备份撤销现有删除记录。
8. 助手管理页接入系统栏/键盘安全区，隐藏重复标题栏，修复顶部导航被遮挡。
