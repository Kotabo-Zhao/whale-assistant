## 预览版的使用路径

- 在桌宠输入第一条消息后可继续发送。预览三的直接聊天会并行判断新消息是否独立。任务只接收本句原文；依赖上轮答复、追加或指代时，保留在原会话等待。窗口显示判断中、排队或接取状态。最多暂存 12 条消息，工单另行持久化。
- 从桌宠聊天或长按菜单打开“我的工具”，点已启用的工坊工具即可在桌宠卡片内使用。需要更大空间或收藏结果时点“展开窗口”。收起工具或关闭桌宠面板会销毁内嵌网页，工具版本变化时会核对当前选择。工坊预览、正式工具和桌宠工具沿用同一套脚本隔离，工具无法自行获得资料、文件、网络或设备授权。
- 在设置的界面主题页可选择简约或可爱，同时单独保留明暗模式和强调色。简约使用紧凑圆角与平面卡片，可爱使用较圆的卡片、淡紫背景和桌宠渐变。已覆盖管理外壳和共用桌宠控件。其余原生页面和 Harness 自身界面仍需按屏复核。
- 只有等待用户或受阻的 Worker 时，不再因为这些工单而维持五秒心跳。界面命令继续通过文件监听唤醒，有历史工单时保留十五秒兜底。未送达回执、镜像写入和真正执行中的工作仍保留原来的活动频率。主机安装的运行环境须更新到 `0.3.55-whale-pet-modes` 才会使用这项改变。

## 原生创造模式的第一条实机路径

Harness 只读会话生成一个 Kotlin 页面。开发者审查它只处理手动输入的文字后，在电脑执行以下命令。设置 JAVA_HOME 和 ANDROID_HOME，并准备本项目 Android 离线构建依赖。
```sh
python scripts/build-native-feature-preview.py examples/native-checklist/Feature.kt --title 清单去重 --out build/checklist-preview
```
输出目录必须是新目录。脚本从受控模板编译，核对独立包名和零请求权限，并输出源码、APK 和含 SHA-256 的清单。每次构建使用新签名。新签名不能直接覆盖同包名旧安装。当前安装由开发者完成，桌宠内审核、启用、撤销、版本回滚与手机端构建仍待实现。
### 预览二十二 · 从桌宠打开原生功能

电脑构建候选时可传入稳定的 --id。同一 ID 下可保留多个已安装版本，一次启用其中一个。工坊通过 Android 文档选择器接收清单，核对固定的原生窗口组件、包名、已安装 APK 摘要、独立 UID 和零请求权限。预览、启用及从桌宠打开均重新验证。导入不会自动启用。工坊与桌宠共用本机启用状态，仅在工具栏挂载时监听变更。点击原生入口成功后收起浮层，让工具获得输入焦点。
### 预览二十三 · 首轮中断后的连续接单

当首条直接回复需要重试时，原请求仍占用自己的对话位置。用户发送不同的消息后，桌宠把它写入独立的待处理记录；判断上下文包含原请求，交办内容只包含新消息。后台回执可以先显示，原对话保留重试入口。普通追问等待原轮结束，再按提交顺序进入历史。已绑定主 Harness 会话时仍沿用该会话的授权和顺序。
### 预览二十四 · 原生版本恢复

工坊按功能 ID 聚合原生版本。卡片记录当前版本和上一次启用的版本，并在同一笔本地写入中更新两者。用户可以展开版本记录预览或切换，也可以直接恢复上一版。每次切换重新验证候选安装包，过期页面的切换请求会被拒绝。未启用版本不能从桌宠启动。旧版本的独立 APK 须仍安装在本机。
### 预览二十五 · 后台状态计数

桌宠接收工单变更事件后合并刷新。收件箱未打开时，使用当前工单索引，只核对仍可能计入运行、待处理、追问的工单及其前置工单。状态改变后更新索引，台账缺失仍在读取时核对。首次载入仍需建立索引。查看具体目标或筛选结果时，页面显示的待授权卡片按条件筛选，全局待办数仍包含待授权工单。
### 预览二十六 · 混合资料投放

Android 系统分享、桌宠拖放与剪贴板投放共用后台解析路径。保留正文的纯文本表示，从 HTML 或 Android 富文本提取有效 HTTP(S) 锚点，已显示的相同地址不重复追加。系统分享标题作为可检索文本保存，附带原件与这段文字关联。已知的投放应用和网页平台不同时，在资料来源中分别显示。来源提示只用于展示和检索。
### 预览二十七 · 桌宠对话布局

两套主题的对话面板共用同一入口顺序。标题区保留后台工单入口，快捷栏聚合资料、工具与会话操作；输入框与发送按钮位于面板末尾。会话操作和工具面板互斥，展开内容与消息状态共用有高度上限的滚动区域。键盘显示时根据剩余空间重新测量。
### 预览二十八 · 大字号与后台状态

桌宠聊天宽度随字体缩放调整，并受当前窗口宽度限制。大字号下标题区留给角色名称和后台计数，状态标签可以换行。输入与发送仍固定在面板末尾。
### 预览二十九 · 资料检索命中段回读

阅读器首次请求由本地资料库根据当前记录选择起始位置。点开分段资料时，以命中块的槽位开始；原件、首块和显式要求从头阅读均从起点读取。显式翻页仍使用上一页返回的游标。原记录已删除或替换时返回缺失状态，避免显示其他段落代替它。
### 预览三十 · 前台历史与备份并发访问

桌宠对话、完整备份和恢复分别创建历史记录实例，它们在同一应用进程内共享原子文件访问锁。导出只读取已提交的快照，并剔除未完成请求。新实例首次写入会先核对本地原文件，读取失败时保留文件；经后续成功读取可继续保存。该机制保护文件完整性，过时的业务请求仍需按各自会话的顺序处理。
### 预览三十一 · 息屏时的前后台分工

流式文本按最新值合并。面板可见时按 32 毫秒的间隔合并刷新，收起或收到屏幕关闭回调后暂停中间文本绘制。恢复可见时主动检查并显示尚未绘制的最新文本。模型请求、工单处理及完成回执使用原有的执行与持久化路径。
### 预览三十二 · 接取前重新核对授权

桌宠路由决定的资料与记忆需求随命令入队。Worker 从 Android 桥接层读取下一批命令时，根据当前设置重新检查访问条件和创作模式。需要等待授权时，先持久化原请求的待授权记录，再从队列移除；同批可执行的其他命令照常返回。恢复沿用请求编号和原始需求，移除也会清理中断时可能留下的同编号队列项。旧命令没有保存的资料需求无法追溯；实际工具仍需执行自身的访问检查。此处覆盖从入队到接取的窗口，已开始运行的 Worker 另行管理。
### 预览三十三 · 多类别检索回执权限

设备桥接层在统一检索每一类数据之前检查授权，并在准备返回整份响应时再次核对所有涉及的类别。单独查询事项时，如结果来自分享资料，还需核对资料权限。任一必需权限被撤回时走既有错误通道，正文为空。此检查约束后续工具响应，已交给模型的内容不会由它撤回。
### 预览三十四 · 执行中受阻工单的授权入口

主应用和桌宠任务卡共用同一规则。工单处于 blocked 状态且摘要包含可识别的资料、记忆或通知权限错误代码时，显示「权限设置」。打开前重新读取工单，核对状态、撤销标记及执行记录，并将目标限制在应用内相应设置页。用户确认授权后，原有继续操作仍向同一工单提交说明。未报告具体错误代码时保留通用继续入口。
### 预览三十五 · 桌宠只读工单的快捷续接

只读工单已报告明确的权限错误时，主应用和桌宠可直接提交「继续原任务」。桥接层检查工单模式、可识别的受阻原因、卡片读取版本、执行台账及所属会话的当前权限。续接命令由工单 ID 与执行轮次确定，重复点击不增加第二份输入。用户仍可补充继续说明；设备操作与创作使用原确认流程。

### 预览三十五后续审计 · 绑定会话并发仍未通过

新增与普通聊天共用断言的绑定会话实机验收。AYANEO 的 read-only Harness 会话路径在 47.226 秒报告「首轮回复已结束，独立工单尚未接取」。目前旁路分类明确排除了已绑定会话；直接交办入口又固定归属任务台，不能只移除前台判断而遗漏父会话权限继承。来源会话持久化、恢复去重、旧运行环境兼容与验收要求见 [绑定会话并发审计](Harness绑定会话并发验收-20261105.md)。此项保持未完成。

### 预览三十六 · 绑定会话独立只读交办

原生侧捕获当前绑定会话，将来源身份随独立只读任务持久化。暂存、重新授权与重复提交继续使用原身份。插件接取时解析已有来源会话，Worker 启动仍继承该父会话的当前权限。旧协议不会收到绑定命令，待接取卡片提示更新运行环境。绑定创作任务暂时仍走原会话，不通过默认任务台扩大权限。

此前预览三十五失败的同一并发断言，在新版主应用及运行环境上通过，另增加完成工单归属断言。当前完成的是绑定会话的只读路径；上节失败记录保留作为修复前基线。

### 预览三十七 · 绑定会话工具草稿

独立创作交办沿用来源会话身份，接取协议升级为第二版。第一版只能接取绑定只读任务，不能误接绑定创作。原生确认草稿创作者时，将原命令中的来源固化为本地授权字段；镜像只能更新执行状态，不能授予或改写这项授权。旧任务台草稿保留兼容路径。

Worker 启动时检查来源会话权限，只读或未知预设导致工单受阻。草稿调用在异步镜像与确认之后、真正调用原生草稿接口之前再次检查来源权限，覆盖等待期间的撤权。恢复权限后仍由原工单继续，草稿不能自动启用。此机制仍属于限定的工具草稿创作，并未完成手机自主修改主应用的完整开发链路。

### 预览三十八 · 普通聊天流的完成边界

直连聊天按服务端 SSE 的 `[DONE]` 标记结束读取，随后由请求层关闭读取器并断开连接。此前仅跳过该行、继续等待 EOF 的逻辑可能让已结束的回复仍占用前台执行线程。工具参数分片继续按索引累积；内容过滤和未完成的断流仍作为失败处理。这个修复不替代意图识别、代理转交与模型响应各阶段的完整耗时诊断。

### 预览三十九 · 直连处理阶段

直连回复用实际执行边界更新临时提示，并通过用户可关闭的诊断记录 route、reply、handoff、submit 的结果与单调时钟耗时。没有新增轮询或持续计时器；每个执行阶段只在开始和结束各记录一次。关闭日志不产生诊断写入，记录失败不影响聊天。实机已验证阶段提示、开关、真实回复及并发接单回归；绑定会话和侧路分类追踪、偶发超时根因仍需继续补齐。

### 预览四十 · 功能工坊入口聚合

原生工坊按打开/预览、管理、工坊设置分层，保留原有启停及版本核对机制。两种界面风格和明暗模式共用操作顺序；按屏宽与字号切换单双列。窗口适配系统栏安全区域，生成工具内容不被宿主重写。AYANEO 验证四种主题组合、两倍字号及工具状态变化，此项仅覆盖工坊与关联工具窗口，不代替其他深层页面的逐屏验收。

### 预览四十一 · 工具窗口布局回归

预览四十共用按钮的纵向满宽参数影响了横向工具栏。新增实机断言先复现标题被挤压，再验证标题独行、操作等宽后的修复。默认与两倍字号通过，实际预览到启用及使用结果入口可用；工坊四主题与工具生命周期回归通过。此项补充了此前仅验证打开与启停、未覆盖布局的证据缺口。

### 预览四十二 · 执行记录空闲读取

Agent 执行记录由五秒轮询改成原生存储变更通知，通知合并后驱动页面刷新。旧环境缺接口或注册失败采用十五秒可见兜底；隐藏与卸载停止无效工作，返回即时读取，慢请求不重叠且不应用过期响应。实机验证静置零重复读取及状态更新链路；长期电量、温升和 Doze 验收仍未完成。

### 预览四十三 · 资料解析失败可恢复性

原件解析新增固定失败类别，收藏阅读及详情给出对应下一步。重试与成功提交清除旧提示，未知异常不泄漏原文。实机验证格式失败、来源和原件保留、重试状态清理及陈旧工单保护。此轮完善失败后的体验，不代替长音频及真实跨 App 多模态解析质量验收。

### 预览四十四 · 解析恢复终止状态
