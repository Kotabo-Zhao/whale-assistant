# 鲸鱼助手 0.3.8-preview.85

根据“动作结束回待机有跳变”和“使用插值提高帧率”的反馈，桌宠加入离线光流中间帧。主要动作移动段从约 80 ms 换帧细分到 40 ms，触摸与收尾移动段为 30 ms；原来的静止停顿保留，原动作总时长不变。手机只播放烘焙好的透明图集，不实时计算光流。

每个非待机动作增加各自绘制的收尾：放杯、合书、坐姿起身、收起手机或放松手势。回待机时先完成当前手势，再播对应收尾，最后接到像素一致的待机首帧；不再直接把持物姿态换成空手待机。新回复、拖动和实际设备控制可以立即打断收尾，业务状态不等待动画。

保留原版 240 张动作关键画面，采用 17 组独立收尾原画，烘焙 488 张实际光流中间帧。手、表情、服装和道具仍属于同一张完整角色画面，不复用公共骨架。透明边缘、翻页遮挡与收尾切图均重新检查。

图集在后台按桌宠实际像素尺寸解码；缓存按显示尺寸收紧，并同时限制图集数量和字节数。静止待机、隐藏、锁屏、熄屏与减少动态继续避免持续刷新，省电模式允许手势和收尾完成后静止。提高画面密度仍会增加素材体积及部分解码开销，不宣称已经证明续航提升。

版本为 .85 / 130，继续保留 .83 合入的主人档案、秘书闭环和统一转述，以及内置 runtime .92。测试、实机录屏与性能对比见《桌宠插值与收尾修订-20261107》；测试通过不替代用户的观感验收。
