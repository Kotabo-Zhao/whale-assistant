# 桌宠形象与动画（2026-10-30）

参考公开社区鲸鱼娘的蓝发、鲸尾和蓝白女仆装特征，使用内置 ImageGen 创作新的原创 Q 版形象，不把社区二创称为 DeepSeek 官方吉祥物。参考：[鲸鱼娘形象来源介绍](https://post.smzdm.com/p/anv9qw6v/)、[社区形象档案](https://fisharchive.cc/)。

生成提示：透明背景的两头身蓝发鲸鱼娘，蓝色鲸鱼帽与侧鳍、蓝白女仆装与白围裙、蓝色鲸尾、完整小脚、清晰轮廓、适合小尺寸桌宠；随后在保持姿态和构图的前提下生成闭眼帧。素材保存为 `whale_maid_open_v2.png` 和 `whale_maid_blink_v2.png`，原 `whale_companion.png` 保留。

运行时按悬浮尺寸采样两帧；眨眼仅绘制眼部区域以减少生成帧其余部位的跳动。头像做小幅摆动和呼吸，点击有短暂反馈；系统关闭动画时不启动运动或眨眼。悬浮窗触摸区域不随头像变换，关闭服务或更换尺寸时释放旧位图与回调。

浏览器对 88px 和较大尺寸的正常/眨眼帧进行了模拟绘制检查，见 `reports/pet_preview_20261030/preview.png`；这不是 Android 实机截图。Android 单元测试、脚本回归和调试构建通过；未连接设备，真实悬浮显示、拖动、输入交互、动画观感、耗电和厂商系统行为仍未验收。
