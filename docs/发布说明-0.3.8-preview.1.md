# 鲸鱼助手 0.3.8 预览一

- 桌宠等待模型回复时可以继续发送。第二句话进入当前会话的队列，输入框可继续编辑；后台任务入口同时显示运行和待处理数量。
- 已启用的工坊工具可直接在桌宠卡片内运行。需要更多空间时可展开独立小窗，关闭后回到来源应用。
- 外观设置提供简约、可爱两套风格，可与浅色、深色或跟随系统组合。
- 等待回答和受阻的 Worker 在没有待发送回执时减少定时唤醒。此变更位于内置运行环境 `0.3.55-whale-pet-modes`。

这是调试签名预览版。同一桌宠会话仍按顺序处理排队消息，尚未开始的消息保存在服务内存中。短时 USB 采样无法证明离电续航改善。[实机记录](鲸鱼助手持续开发与真机日志-20261104.md) · [架构对照](SuperAgent对照与桌宠交互-20261105.md)
