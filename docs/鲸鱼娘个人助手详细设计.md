# 鲸鱼娘个人助手详细设计

本文是拟开发设计，不代表功能已经实现或已经在荣耀 Magic6 验证。配套路标见《鲸鱼娘个人助手设计与路线图》。核心目标是让助手能理解用户允许提供的信息、记住偏好、主动提醒并可靠执行任务；免 root，以悬浮气泡为主，重要事项使用通知。

## 1. 总体结构

### 统一对话与移动插件适配（新增要求）

用户打开助手后应直接进入包含鲸鱼娘、Harness 对话和设置入口的统一界面，不应依赖再点击一个独立的 Harness 入口。主界面已接入独立的受限原生 WebView，复用本地凭据校验、导航限制与文件选择；不通过普通 iframe 传递认证信息。首次安装、模型未配置、运行环境未就绪、启动失败和用户手动停止时保留设置与重试入口。独立 `HarnessActivity` 作为回退保留；返回、悬浮窗、OAuth 与文件选择尚需在设备上回归验证。

市场页面应通过应用的移动插件管理器进行受控安装，并在下载前检测运行时版本、依赖、原生模块、平台和权限。普通共享依赖的版本冲突可采用插件事务目录中的私有依赖，宿主核心单例仍必须使用受控的运行时实例；不执行安装脚本、不覆盖其他插件，失败保留原版本。目标插件需要桌面 GUI、系统权限或不兼容原生模块时应明确阻止或提示，不能声称所有插件均能自动适配。现已在应用插件页增加按需加载的社区目录和受控安装入口，并对普通依赖冲突做隔离；预置 dshmarket 的安装入口对目录明确映射的 npm 包提交待确认请求，由用户在插件管理中停止运行环境并确认；指定版本、强制安装和非 npm 来源不支持此路径。市场其他操作及手机兼容性尚未真机验证。

```text
通知/日历/用户分享/使用统计 ──> 授权与筛选 ──> 本地信息库 ──> 分类与候选事项
                                                       │
对话/语音 ──> Harness ──> 记忆检索 <── 本地记忆库    ├──> 简报与提醒 ──> 气泡/通知
                    │                                  │
                    └──> 任务计划 ──> 逐步观察/执行/核验 ──> 任务记录
                                             │
                                     无障碍 / Shizuku / 系统 API
```

优先使用已有 Android 原生桥、Harness 和悬浮服务。数据存储位于应用私有空间；模块通过明确的输入输出交互，不能由通知正文或网页文本修改系统指令。插件、模型和网络都是可替换组件。各数据源和对外发送分别由用户控制；用户启用某种采集不等于允许把其全部内容传给模型。

## 2. 看懂信息：通知、简报和知识

### 2.1 通知管家

- **入口**：设置页分别开关通知采集、来源应用、分类和主动提醒；用户可以查看、删除已有数据。首次启用时跳转系统通知读取授权，不偷偷开启。
- **处理**：监听系统提供的新通知，跳过本应用、持续型和系统标记为 secret 的通知；按用户来源设置过滤，再执行敏感信息识别和去重。保留应用名、通知时间、摘要和分类；敏感规则只是尽力过滤，不保证识别全部私人内容。
- **分类**：先用本地可解释规则归为日程待办、物流出行、消息或其他，并记录依据及来源；可选的模型分类必须由用户明确启用、展示传递内容及服务提供方。分类不能当作事实或“重要性已确认”。
- **候选事项**：提取“会议、取件、待回复”等候选，附原始来源和时间；缺少时间、地点或对象时标为待确认，不自动创建日历事件或发送回复。
- **失败**：权限撤销、服务断开、无记录、过滤失败分别显示原因；没有记录只能显示“没有可用数据”，不能说“没有重要通知”。
- **当前状态**：通知采集、本地规则分类及按已出现应用排除新通知的代码已加入；简报、应用排除的新代码尚未通过 Android 编译与真机验证。当前数据上限为 50 条、7 天。

### 2.2 每日简报

用户设置时段，选择已授权的数据源；生成器汇总当天日历、待办、最近通知、天气等，并对每一项显示来源和更新时间。缺失权限、未联网、没有天气来源时明确标为“未获取”，不填空白猜测。点击条目可跳转源应用或查看本地详情。气泡默认只显示摘要，通知不在锁屏暴露正文；用户可以关闭或调整频率。可先实现手动生成，后接任务调度；本地通知统计不等于完整日报。

### 2.3 用户分享的知识

通过系统分享或文件选择器接收用户选定的网页、文本、图片、PDF；保留来源、采集时间和用户可见的处理状态。先提取文本/OCR，再由用户选择仅本机检索或提交给指定模型整理。资料可搜索、删除、重新处理；无法识别的文件显示失败，不将空结果记为成功。大型附件采用容量上限与清理策略，具体阈值开发时在设置中列明。

## 3. 记住偏好：长期记忆和习惯

- **数据模型**：记忆项包含 `id`、内容、类型（偏好/事实/任务）、来源类型与来源引用、创建及修改时间、用户确认状态、可选失效时间。保存原文引用时必须尊重源数据删除和权限撤销；从通知得出的候选默认只在本机，是否长期记住由用户决定。
- **写入**：用户明确说“记住”可写入；模型从对话或通知推断出的偏好先作为候选，展示内容和来源后再由用户确认。相似内容提示合并，不静默覆盖互相冲突的信息。密码、验证码等敏感信息拒绝保存，但规则存在漏判风险。
- **读取**：按任务需要检索少量相关记忆，展示哪些会发给模型和服务提供方；记忆不可用或用户禁用时，模型应继续处理并说明缺失，不得猜测。
- **管理与迁移**：提供搜索、查看来源、编辑、删除、清空、导出；旧条目没有来源就标记未知。迁移前备份，原子写入，遇到未知版本或损坏保留原文件并报错。删除后清除可追溯派生项，无法删除的外部模型服务副本明确告知。
- **习惯学习**：经用户开启后，在本地基于使用统计和已授权事件生成建议，如“是否把常用流程设为快捷任务”；可关闭、忽略或删除候选，不能以频繁使用推断敏感属性。
- **当前状态**：基础保存、检索、删除已有；新来源字段和展示已写代码，旧来源显示未知，但还未经过 Android 编译及设备升级测试。已支持用户管理、编辑、导出与经确认的导入；已支持从通知生成待核对的规则候选；通用语义学习和从使用记录自动形成长期记忆尚未实现。

## 4. 主动提醒：调度、触达和鲸鱼娘

### 4.1 提醒数据与调度

提醒包含 `id`、内容、来源、触发时间与时区、重复规则、触达方式、状态、上次触发和用户操作。状态为草稿、已安排、已触发、已取消、失败；生成和触发采用幂等标识，重启恢复时避免重复通知。修改或取消立即更新持久化数据并取消旧调度；错过的任务标记错过，由用户选择补发，不静默连续触发。

普通后台整理用可延迟的系统任务；用户明确要求准时的提醒才评估系统精确闹钟能力和权限。启动失败、权限不足、系统限制、省电延迟和时区变化必须可见，不能承诺手机始终在线或秒级执行。开机恢复依系统允许的启动方式进行，先恢复用户已启用的任务，不自动打开界面。

### 4.2 交互和防打扰

鲸鱼娘气泡可显示“有一条待办/通知”，点击后展示详情及处理、稍后提醒、忽略操作。重要事项可发系统通知；通知正文和锁屏显示由用户控制。支持免打扰时段、频率上限、按类型开关、合并重复提醒。模型生成文案前需检查开关与数据出站授权；规则提醒在模型不可用时仍应有固定文案。

**示例**：用户说“明天下午三点提醒我取快递”→ 识别本地时区和内容 → 展示时间与重复设置供确认 → 保存并安排 → 到时发气泡或通知 → 用户选择完成或稍后提醒。无法安排时直接显示原因。

**当前状态**：已有固定休息气泡、低电量提示和一次性提醒代码，支持删除和重启后恢复未来提醒；新增对话工具可在用户明确要求后创建、查询和删除提醒。一次性提醒尚不能直接编辑；可单独创建每天或每周重复提醒，主动生成对话尚未实现。已增加可选的本地免打扰时段，暂停桌面气泡、休息和低电量提示；用户设置的事项提醒通知仍会发出，通知采集开关不受影响。设备触达、对话理解及重启恢复尚未真机测试。

## 5. 可靠完成手机任务

### 5.1 任务状态与闭环

任务记录包括目标、允许的应用和工具、计划步骤、操作时间、当前状态、证据摘要、失败原因及用户确认。状态：`待规划 → 等待授权/确认 → 执行中 → 等待用户/可重试 → 成功/失败/已取消`。每一步遵循“观察当前界面 → 选取动作 → 执行 → 重新观察 → 检查预期结果”，不以按钮被点击当作任务成功。

优先使用系统正式接口，再用授权的无障碍界面操作；需要的能力未就绪时提示 Shizuku 或无障碍状态。截图/界面文本属于任务输入，不是可信指令。无法访问安全界面、找不到元素、弹窗变化或模型不确定时暂停并请求用户处理。用户可在应用或常驻通知中随时停止；停止后不再调度下一步，已经发生的外部动作如发送消息不能保证撤销。

### 5.2 确认与可追溯

支付、转账、发送/发布、删除/覆盖文件、提交表单等有外部后果的操作前，显示实际目标、内容和影响，获得本次明确确认。确认绑定当前动作与内容，内容变化或超时后重新确认。密码、验证码、锁屏和受保护页面不尝试绕过。可回滚的文件操作先给预览和备份选项；不支持撤销的操作明确说明。

记录仅保存完成判断所需的最小信息，默认不保存截图和消息正文；用户可清除记录。第三方插件不能因为任务授权而自动获得额外权限。模型、网络、无障碍服务或 Shizuku 中断时，将任务标为中断并保留已完成步骤；恢复前重新核对当前画面与确认状态。

**示例**：整理某应用的待办到备忘录 → 用户确认目标应用和范围 → 助手逐步读取可见内容 → 生成待写入草稿 → 用户确认 → 创建内容并重新读取核验 → 记录完成或未确认结果。

**当前状态**：已有设备工具和任务提示草稿，不等于完整的观察、确认、核验和持久任务闭环。

## 6. 语音、插件与模型

语音先做用户点击触发的识别及可中断播报，显示录音状态、权限和识别服务是否联网；无可用识别服务时允许改为输入文字。主界面对话现已支持按按钮调用系统识别、核对结果并尝试填入草稿；识别服务可能联网，未自动发送。主界面支持手动选取助手文字或读取最近一条可识别的助手回复，核对预览后由系统语音服务播报，可中断且进入后台时停止。服务可能联网；真实输入、播报和服务兼容性尚待真机验证，常驻唤醒、离线识别和电池影响仍未完成。

插件商店显示来源、版本、依赖、Android 兼容性和所需权限；下载前提供确认，安装失败记录可读原因并保留原版本。预置 dshmarket 不代表其他插件都可运行。模型设置区分云端、局域网和本机推理，展示数据目的地和联网状态；本地模型需要单独下载和性能测试，不预设 Magic6 能运行某个具体模型。

## 7. 开发顺序与验收

1. **基础可用性**：恢复 Android 构建工具链；真机验证已有 APK、权限及 Shizuku。各状态要有明确错误，不清除用户数据。
2. **信息与记忆**：完成来源授权、通知筛选、分类、简报、记忆管理和旧数据迁移测试；离线、空记录、撤权、损坏与清除均需验证。
3. **提醒**：持久化和调度、气泡与通知、取消、重启、时区/省电/权限撤销；区分自动化测试与真机实际触达。
4. **任务闭环**：先在一两个经用户授权的应用完成可观察的端到端流程，再扩大到更多应用；验证暂停、拒绝、失败和中断恢复。
5. **语音及扩展**：识别、播报、知识库与插件能力按需增加；分别测网络、权限、数据去向及性能。

完成定义：代码和相关测试通过、说明已知限制，并在 Magic6 上验证该功能的实际触发及结果。电脑测试通过、APK 成功安装、模型宣称任务成功都不能单独证明真机功能已完成。


### 通知候选跳转原通知

用户可在通知候选详情中选择打开仍有效的原通知或来源应用首页。原通知仅通过已连接的通知监听服务读取当前通知，核对来源包、通知键摘要、当前内容摘要和 PendingIntent 创建者后，由用户点击触发；没有保存 PendingIntent。通知消失、内容变化、权限撤销或系统限制时提示不可用，旧记录仍可打开来源应用首页。此功能尚未在荣耀 Magic6 和第三方应用上验证；系统接受请求不保证目标应用打开指定页面。


### 长期记忆关联查找

对话工具优先执行原有精确包含检索；没有精确命中时，使用本地词语重合查找少量关联项，返回 `matchMode=related` 和核对提示。它不是语义理解，可能漏掉或误匹配，不能把相关结果当作已确认事实；待确认候选仍不会提供给模型。助手设置新增按内容搜索全部记忆与候选的入口。检索仅在手机本地执行，但返回的记忆可能由当前模型服务处理，仍受记忆开关控制。该功能尚未在荣耀 Magic6 验证。


### 本地简报中的日历

用户可在助手设置中主动申请只读日历权限；打开简报时，在后台线程临时查询系统可见日历中当天的事件实例（含重复事件），显示时间、标题、时区和读取时间，最多展示 20 条并提示截断。未授权、系统读取失败和没有日程分别显示；日历内容不保存，也不自动发送给模型。系统日历的同步状态和可见范围由设备决定，跨天、全天和重复事件以及 Magic6 设备权限表现尚待真机验证。


### 对话中查询今日日历

手机助手提供单独的“允许助手对话访问今日日历”开关，默认关闭；开启前说明当前模型服务可能接收日程标题和时间。该开关与系统日历权限都通过时，助手可以按用户请求通过只读工具查询当天可见日历，返回读取时间、时区和截断状态；未授权或读取失败不当作空日程。日历文本是不可信数据，不可触发自动操作。该功能需要内置运行环境 0.3.13，尚未在荣耀 Magic6 上验证。


### 临近日程气泡

用户可单独开启日程气泡，需日历读取权限；悬浮助手运行、屏幕解锁且不在免打扰时，后台约每 5 分钟检查未来 15 分钟即将开始的可见非全天日程。气泡只显示数量，点击打开本地简报，不发送标题给模型。成功显示后记录有限的事件标识摘要以减少重复；可手动清除。最多检查前 20 条，系统省电、服务停止、锁屏、权限或气泡限频可能导致漏提醒，无法保证准时触达。此功能尚未在荣耀 Magic6 真机验证。


### 鲸鱼娘设置中的语音接回对话

从鲸鱼娘设置启动系统语音识别后，可在核对结果时选择填入已打开的主对话草稿；只在进程内暂存，验证原对话页、授权和短时有效期后插入，不自动发送。没有可用会话、页面切换或输入失败时提供复制入口；进程被系统结束时暂存结果可能丢失。识别服务可能联网，该流程尚未在荣耀 Magic6 真机验证。


### 常用应用建议

用户可单独开启“提醒我整理常用应用”。在使用情况权限已授予、悬浮助手运行且解锁、非免打扰时，助手在本机按最近约 7 天的前台使用时长提出候选；不推断敏感属性，也不会自动加入快捷方式。气泡最多每天提示一次，点击后可核对应用和估计时长并选择加入；系统使用统计可能不完整，快捷方式已满或应用不可启动时不推荐。数据不发送给模型，不持久化使用时长；后台服务及 Magic6 真机效果尚未验证。


### 任务回执与未验证状态

点击、输入和滚动即使选择不检查界面变化，也需要对应本次任务、步骤和尝试的实际动作回执；缺少回执时结果记为不确定，不放行后续步骤。没有独立验证的已记录步骤在任务卡片中明确显示“结果未验证”，不把整项任务称为已经完成。当前全局返回动作尚无绑定回执和跨应用前台变化证明，包变化仅凭调用者报告不能算验证成功；仍需建立完整的返回动作证据链并做真机回归。


### 主屏任务返回动作

长期记忆文件读取使用严格 UTF-8 解码，并检查版本、条目数量、字段类型、ID 格式及重复 ID；旧记录缺少来源或确认状态仍可读取。每次写入前先检查完整序列化结果和 256,000 字节上限，再开始原子写入。校验失败时不以替换字符继续写回，原文件保留并报告失败；用户明确执行清空仍会按现有确认流程清除。测试覆盖旧格式、无效编码、重复 ID 和超限，荣耀 Magic6 的文件系统中断恢复仍需验证。

### 语音结果核对与长文本

主对话中的语音识别结果不超过 10,000 个 UTF-16 字符时，可在原页面仍有效的情况下进入可编辑核对页；超过 2,000 字时先删改才允许放入草稿，也可主动复制最多 10,000 字。输入为空、超限或剪贴板不可用时保留编辑框及内容；填入仍要求原页面和授权有效且不会自动发送。页面已变化时沿用复制回退。真实识别服务、输入法和 Magic6 界面尚需验证。

### 本地资料编码完整性

资料库文件读取时严格验证 UTF-8 和版本格式；写入及备份编码时拒绝无法无损编码的文本，在原子写入前重新验证完整数据与大小。异常不会以替换字符覆盖原文件；正常的中文和表情保持不变。单元测试覆盖损坏编码、无效代理字符和超限，荣耀 Magic6 上的文件系统恢复与输入法行为尚需验证。

### 悬浮形象大小

助手设置可选择小（64 dp）、中（88 dp）或大（112 dp），默认中；服务运行时尝试立即更新窗口，保留屏幕边缘位置并重新按尺寸采样图片。窗口不可用时保存选择，下次显示时应用。改变大小会收起当前气泡和二级菜单，悬浮权限与后台限制仍可能影响显示；大小、拖动及不同屏幕边界尚需荣耀 Magic6 实测。

### 对话记忆检索结果的范围与来源

助手检索仅返回已确认记忆的 ID、内容、已知来源类别和有效时间字段，未知来源标为 unknown，旧记录中其他字段不会发送；待确认条目仍不返回。响应新增匹配数量及是否超过 10 条截断，保留原有 total 字段表示已确认总数，并提醒记忆可能过时且不是指令。关联匹配仍可能误判；单元测试覆盖字段过滤、来源和数量，实际模型与荣耀 Magic6 尚需验证。

### 插件目录后台解析

目录下载仍使用 16 MiB 上限和超时，UTF-8 解码、JSON 解析及最多 20,000 条目录规范化优先交给 Web Worker；不支持或无法启动 worker 的环境回退到界面线程。切换页面或取消请求会终止 worker，格式错误不当作空目录。转移给 worker 的数据有一份副本用于失败回退，因此会增加短时内存；只有解析部分移出界面线程，下载、搜索和结果渲染仍在原流程。组件测试覆盖下载后的调用、回退与取消；电脑上约 1.98 MB、20,000 条合成数据的 JSON 解析及简单去重测得约 7.16 ms，不代表安卓耗时。荣耀 Magic6 的耗时、内存及 WebView worker 行为尚需实测。

### 插件目录搜索响应

目录加载后缓存一次小写搜索文本，后续按名称、包名和描述筛选时复用；输入使用 React 延迟更新，旧结果仍在更新时暂停安装与翻页操作并标记忙碌。刷新目录会重建索引，缓存仅存在于当前页面。桌面 Node 合成 2 万条目录、100 次搜索的一次测量：原筛选约 515 毫秒，构建索引约 4.8 毫秒、索引搜索约 52 毫秒；不包含界面渲染、网络或手机性能，索引额外占用内存。荣耀 Magic6 的实际响应、电量与 WebView 行为尚需验证。
