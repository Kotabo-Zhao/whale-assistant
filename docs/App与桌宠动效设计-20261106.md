# App 与桌宠动效设计及覆盖记录

版本：0.3.8-preview.72 引入动效，preview.73 补充竖屏高度。设备：AYANEO Pocket S。

## 统一规则

“深海·专注”使用 210–220 毫秒的内容过渡，“月汐·陪伴”使用 260–270 毫秒的柔和过渡。浅色和深色共用节奏，颜色、圆角和插画沿用各自主题。按压反馈约 130 毫秒，悬浮窗口进入约 220 毫秒、退出约 140 毫秒。设备受控标识进入 120 毫秒，起始即保持 88% 不透明度。

动效主要使用透明度、位移和缩放。导航、键盘避让、窗口宽高、拖动和交互坐标继续由原有布局逻辑管理。页面动画作用在主内容的子节点；导航栏和独立对话 WebView 的定位容器保持稳定。新消息只在创建气泡时进入，流式文本更新不重复执行动画；重开桌宠时历史消息直接还原。

## 覆盖范围

| 区域 | 动效及反馈 |
| --- | --- |
| App 一级页面、设置子页 | 主内容轻移淡入，导航文字和背景过渡，选中图标轻微强调 |
| App 确认框、资料阅读器、菜单、弹出面板 | 背景淡入，面板轻移及微缩放进入 |
| App 资料录入、编辑、任务派发、任务卡、恢复核对面板 | 面板进入、详情内容淡入、控件按压和焦点反馈 |
| App 通知提示、按钮、输入框、选择器、开关 | 短时面板进入，颜色和边框过渡，开关滑块缓动 |
| 主对话 | 原生对话面进入，工具栏按钮与输入框反馈，菜单和对话框进入；与 App 使用相同动画开关 |
| 原生设置与管理页 | 页面内容进入、Activity 窗口进入退出、系统控件反馈 |
| 桌宠主体 | 保留已有接单、工作、询问、庆祝、触摸和挫折动作；增加点击反馈及悬浮窗口进入退出 |
| 桌宠对话 | 聊天窗口进入退出、新消息气泡进入、内嵌工具进入与返回对话过渡 |
| 桌宠提示和资料卡 | 保留提示气泡进入及可访问的停留时长，复用原生涟漪反馈 |
| 独立悬浮 HTML 工具 | 工具窗口进入退出、展开后的窗口反馈，原有拖动和折叠布局继续工作 |
| 设备受控状态 | 快速显现控制条，保留暂停、继续、停止的即时响应 |

React 弹层卸载时仍立即关闭。主对话使用上游消息组件原有的流式呈现，本轮新增统一的对话面、菜单和控件动效；没有给每个 token 叠加动画。用户创作的 HTML 页面、外部 App 和系统键盘的内部动画由各自所有者控制。

## 减少动态效果与资源

跟随 Android 的动画开关与网页 prefers-reduced-motion；App 恢复到前台、切换主题和主对话主题注入时同步状态。减少动态效果时，网页动画和过渡关闭，原生内容立即显示，新悬浮窗口不使用进入退出动画；桌宠姿态回到静态中性帧。

本轮没有增加装饰性常驻循环、逐 token 动画、背景粒子、全局 WebView 计时器或全局 MutationObserver。已有等待状态和桌宠动作保留各自生命周期管理；减少动态效果时桌宠动作定时检查降至一秒一次，以便运行中切换系统设置仍能生效。

## preview.73：竖屏手机优先

用户明确以竖屏手机为主。自动高度改为短内容紧凑、长内容增长至约六成可用高度后滚动，通常不超过 480dp。键盘出现时优先保证输入区和至少一行消息，展开的菜单会在剩余空间滚动。手动“低 / 高”设置保留，所有模式继续受当前可用区域约束。

定位改用扣除状态栏后的同一坐标区域，避免桌宠靠近底边时，输入框被挤入键盘。菜单展开和收起也会重新计算高度。大字号竖屏的快捷按钮采用图标在上、文字在下，保留原有完整名称和触摸面积。

在 Pocket S 上设置手机尺寸区域验证：390dp × 840dp、1.0 / 1.6 倍字号，360dp × 800dp、1.0 倍字号。四种主题、桌宠上中下三个位置共 36 个组合完成短→长→短消息和真实键盘回归；正常输入、展开选项时输入区均可见，收起后恢复高度。荣耀当前未连接，这些结果是 Pocket S 的手机视口实测，不能当作荣耀安装验收。最终大字号按钮与工具组合复测见 preview.73 发布说明。

界面截图和录屏保存在本机 build 目录，录屏使用测试文案展示实际 UI，不能作为模型完成真实任务的证明。


最终竖屏复测直接检查实际主题配色，使用独立测试 App 作为背景，避免混入用户内容。36 组均通过，最终日志为 p73-device-phone390-palette、p73-device-phone390-font16-palette、p73-device-phone360-palette。大字号快捷按钮单行可读；横屏和大字号竖屏工具组合分别 11.956 / 9.981 秒通过。

切页帧率：首次采样 P95 32 ms，预热后 P95 18 ms、249 帧中 2 个超时帧；减少动态效果 P95 16 ms、58 帧中 1 个超时帧。样本和帧数不同，不推导总体优化比例。相关记录为 build/p73-navigation-frames.json、p73-navigation-warm.json、p73-navigation-reduced.json。

## preview.77：控制状态由桌宠表达

独立手机操控状态条已删除。观察时持手机看屏，执行时抬手点按，等待时保留持握，暂停时举手并显示暂停符号，停止时收手机并示意停止，异常时显示琥珀色提示。道具绑定现有网格手腕，420 ms 抬手过渡；真实暂停、停止立即抢占其他动作。

轻动作 20 Hz，活跃动作沿用 30 Hz，省电模式 12.5 Hz；息屏与不可见时不排动画帧。减少动态效果保留能读懂状态的静止姿势。两套主题的浅深配色由现有主题色驱动，不增加新主题或设置项。

控制期间单击桌宠打开暂停、恢复与停止菜单；恢复只接受新动作，旧队列不重放。Pocket S 原生绘制、四套配色、减少动态效果与真实触摸结果见[本轮实测](桌宠状态与执行恢复实测-20261106.md)。
