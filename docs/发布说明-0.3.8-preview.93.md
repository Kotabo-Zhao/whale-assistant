# 鲸鱼助手 0.3.8-preview.93

修复主对话本地重试索引损坏后持续发送失败，以及 Host 已确认接收、本地清理失败却向用户报告发送失败的问题。待发记录数据库打开或事务超过 10 秒时会退出等待，迟到的打开回调不能补写已经超时的请求。恢复记录读取结束后会再次核对所选会话。Host 也会检查持久化的入队记录，确保消息被取出、但正文尚未写入时，按原编号重试只执行一次。

修复完整备份拒绝应用内置秘书事项触发器的问题。恢复只认可应用定义的触发器名和 SQL，先清除旧表内容，再导入新数据，避免删除旧事项时连带删除刚恢复的秘书记录。导入前会检查已有工作区数据能否合并。

完整备份现在能往返保存长对话、较大的中文工作区、会话引用和超过 200 个桌宠会话。损坏的桌宠历史、会话引用和工作区记录会使导出明确失败。读取已有数据失败时，后续写入不会以空集合覆盖它。

验证使用隔离的源库和目标库。AYANEO 实测导出、恢复长中文对话、300 条工作区记录、201 个桌宠会话和同编号的秘书事项，并验证损坏目标不会提前替换数据库。篡改过的同名触发器仍被拒绝。消息故障回归覆盖本地索引损坏、确认后清理失败、存储打开和事务超时。脚本测试 531 项通过、4 项跳过，Android 单元测试通过。
