# 预览四十七：权限保存与状态读取一致性

修复根通道设置页中的并发显示问题：用户保存权限开关时，旧查询可能仍在等待返回；此前新焦点事件也会继续发起读取。保存开始后，现在作废此前查询，并暂缓新的状态读取，保存成功使用写入接口返回的真实状态。保存失败仍显示错误并重新读取设备状态；重复写入和页面离开后的过期写入结果不会再次更新界面。

这不改变 Worker 工具权限表、root 策略或 KernelSU 授权，只修正设置页对设备状态的呈现。

新增确定性组件测试构造“旧检测未结束 → 用户保存 → 焦点事件 → 保存完成 → 旧检测迟到”的顺序，确认保存期间不多读，旧结果不能把开关覆盖回去。修复前观察到 3 次读取而预期为 2 次；初始测试夹具未配置多余读取返回值，还引发了 undefined 渲染错误，最终已补齐夹具默认值。该附带错误不是已证明的产品原生返回异常。
