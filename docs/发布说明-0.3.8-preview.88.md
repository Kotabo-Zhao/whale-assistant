# 鲸鱼助手 0.3.8-preview.88

修复阅读、书写、控机、回复和拖动等状态互相打断时直接换图的问题。17 个非待机动作各有一条进场，与原有动作、收尾和待机的端点逐像素接合。动作切换以窗口正在显示的帧为起点。新事件可随时改变目的动作，尚未解码的图集从入口开始播放。

阅读切到书写时，鲸鱼娘现在先合书收手，再坐下拿笔。完整的站坐切换在 Pocket S 回放中约花一秒。减少动态仍显示静态姿态，省电待机没有固定刷新回调。

Pocket S 用同一组状态事件采样了修复前后的实际桌宠绘制帧。约 33 毫秒一次的采样中，阅读到书写的最大相邻画面差异从 14.2% 降至约 5%，书写到控机从 14.0% 降至约 5%。指标计算预乘 RGBA 四个通道的平均绝对差，仅描述这一段回放。

单元测试遍历包括饮水在内的 18 个动作之间的 306 种不同状态切换，并覆盖冷加载、重复反应、连续改向和省电待机。原有 35 张主体及收尾图集与 .87 完全一致。新增图集的 544 格来自对应动作的演出与离线插值。缓存上限仍为三张图集、32 MiB。

荣耀 Magic6 和 AYANEO Pocket S 均保留数据安装了版本码 133，设备 APK 与本地安装包的 SHA-256 一致，为 `2220f0b7c70fef8199870ddf6a2803870a5f5a3e6b5cd1f49e0ad42782ffb960`。内置运行环境为 `0.3.92-whale-pet-front`。
