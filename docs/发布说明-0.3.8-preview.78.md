# 鲸鱼助手 0.3.8-preview.78

本版丰富桌宠全部现有状态的动画，并拆分之前共用动作的思考、工作、回复、庆祝和触摸。运行环境仍为 `0.3.83-whale-screen-coordinates`，本次无需替换 Ubuntu 系统目录。

- 覆盖待机、接单、思考、工作、询问、回复、完成、受挫、触摸、主动提醒、拖动，以及观察、操控、等待、暂停、停止、异常共 17 类状态。
- 增加托腮、书写回看、单眼眨动、递信、拖动平衡等动作，搭配随主题变色的少量矢量图案。普通回复与任务完成使用不同动作。
- 手机道具缩小并下移，扫描、点按和等待屏幕具有独立节奏；控制状态继续优先于聊天与装饰反应。
- 两套主题的浅深四种配色、减少动态效果、省电及隐藏停帧继续统一生效。没有增加模型调用、逐帧位图或独立状态窗口。

设计、真机结果和动画预览见[桌宠全状态动画](桌宠全状态动画-20261106.md)。
