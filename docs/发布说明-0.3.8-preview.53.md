# 预览五十三：故障模拟与失败话题恢复

按用户要求先扩展故障模拟，再安排荣耀安装。本轮在本地 HTTP 夹具和 AYANEO 隔离测试环境验证，未使用真实模型，也未修改用户资料、凭据或权限。

## 本轮修复

1. 模型以长度上限结束、异常结束原因或仅发送结束标记而未完成回合时，原实现可能将半句保存为完整回复。现在只有正常文本或工具结束状态可以继续；流内错误、损坏 JSON 和异常工具参数明确失败。
2. 限制 HTTP 响应为 512 KiB、展示文本为 64,000 字符、工具调用最多 8 项和单项参数 8,192 字符。超限中止，不继续扩大流式界面和内存占用；普通模型请求的生成上限未调整。
3. 凭据拒绝、限流、服务不可用、重定向、连接失败、超时和传输中断分别提示原因。不展示服务端错误正文，不新增自动重试，避免不确定结果下重复执行。
4. 原实现中，只要有后续排队消息，“新话题”就静默无效。现在等待判断结束后，可以归档原会话并开启新话题；旧队列留在“待处理消息”供明确恢复，不自动重放到新话题，并清理旧追问和失败消息引用。仍在分类的消息会提示等待，不与正在接取任务的分类线程争抢状态。

## 故障矩阵

| 场景 | 结果及证据 |
| --- | --- |
| 长度截断、未知结束、缺少结束原因 | 新回归先失败，修复后拒绝将半句当成功 |
| 超大流文本、超大 HTTP 响应、异常工具参数 | 达到客户端上限后失败，无完整回复提交 |
| 损坏 JSON、流内错误 | 失败提示，不泄露提供方错误正文 |
| HTTP 401 / 429 / 503 / 302 后恢复 200 | 每次仅处理对应请求，无重定向或自动重发；下一次正常成功 |
| 服务连接拒绝 | 失败后同一执行线程可以继续下一回合 |
| 响应正文实际长度短于声明 | 报连接中断，不接受半份正文 |
| 服务无响应且另有排队消息 | AYANEO 旧版实际失败；修复后结束等待、新话题、保留队列及下一条回复通过 |
| 关闭重开悬浮窗 | 结束等待仍可操作，原消息保留 |
| 记忆授权撤销 | 后续增删改查拒绝，独立权限与总开关按现有规则生效 |
| 聊天记录损坏、并发保存与导出 | 已有保护回归通过：拒绝覆盖损坏记录，保留完整快照；导出不夹带待执行请求 |

验证：Android 单元测试报告 1,841 项，1,804 通过、37 跳过、0 失败；新故障矩阵 6 项及既有操作取消 5 项通过。脚本 450 项通过、4 跳过，质量门禁通过。AYANEO 最终包 8 项设备测试 1.486 秒通过。网页代码未修改，未重复整套前端测试；沿用 .52 已验证的网页资源。

设备故障测试使用真实悬浮窗、回环 HTTP 服务与隔离本地文件。未做真实运营商断网、系统强杀、存储空间耗尽、长时间后台分类积压或持续热功耗测量；不能将本轮结果表述为全部异常已消除。荣耀仍待安装复测。
