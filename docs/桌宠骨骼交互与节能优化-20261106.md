# 桌宠骨骼交互与节能优化 · preview.82

用户指出表情僵硬、动画逻辑不合理、耗电，以及杯子、书、手机像直接贴上去的道具。本轮保留角色原画，调整原生动画、抓握约束、状态抢占和刷新生命周期。

## 问题与修改

| 原有问题 | 修改 |
| --- | --- |
| 道具跟随手腕的位置，角度却只取身体或手腕角度的一小部分；另一只手没有共用接触坐标 | 新增胸部局部坐标中的道具姿态；肩、肘两骨求解到手腕，手腕再对准真实手部抓握点。渲染与双手目标共用坐标；状态融合后再求解，减少滑手与穿透 |
| 杯子始终挂在手边，没有喝水过程 | 双手持杯，预备、举杯、杯沿接触嘴部、短暂停留、放回；嘴部目标跟随头部骨骼，手腕在举杯中改变角度以保持可达 |
| 书本只附着左手，另一只手没有翻页动作 | 左手托书，右手移到页面、带起页面、松手让纸落下并收回；翻页结束换到下一页，不倒放回原页 |
| 手机、触屏手和点击图案不在同一坐标系 | 左手持机，右手指随点按包络靠近并落到屏幕触点，点按之间收手；观察、等待双手持握，暂停放低手机并举手 |
| 其他道具旋转与手臂不一致 | 接单板、问答卡、星杖、纸巾、抱枕、信封及停止牌同样走持握约束；去掉手机状态额外叠放的放大镜、沙漏、扳手等无必要道具 |
| 编舞闭眼量被后续表情覆盖为零 | 保留编舞眼睑；自然眨眼避让主动闭眼、笑眼和单眼动作 |
| 闭眼与睁眼贴图半透明重叠，有两套睫毛和虹膜 | 中间帧用几何眼睑覆盖，完全闭眼用原画不透明眼层；移除每只眼睛的全角色离屏透明图层 |
| 张嘴和夸张表情在整个状态中保持不变 | 接单、询问、提醒先表达再放松；回复口型收尾；庆祝闭眼后重新睁眼；异常表情适度缓和 |
| 同时有运行和待回答任务时优先显示工作；新问题仍播放旧回复 | 待回答优先于其他后台工作；新对话、拖动清理旧的短时回复；真实控制状态仍优先 |
| 多个眨眼定时器、系统关闭动画后每秒轮询 | 自然眨眼并入主时钟；系统动画设置观察器直接停帧、恢复；隐藏、脱离窗口、锁屏、息屏、减少动态效果不保留动画回调 |
| 恢复或省电广播先回静止帧，容易跳一下；拖动阻尼随帧率改变 | 从当前画面连续恢复；省电更新不强制重置姿态；按真实时间衰减拖动倾斜 |

## 动作预算

安静待机约 5 次/秒，观察、读书、待回答约 12 次/秒，书写和点按约 20 次/秒；举杯、翻页、眨眼、拖动、反应和过渡约 30 次/秒。等待、暂停、停止和异常维持约 5 次/秒。省电时普通循环约 4 次/秒，短时交互最高约 15 次/秒。业务事件可立即唤醒一帧，不必等待安静模式的间隔。系统禁止动画时保持有意义的静态状态。

这些是调度上限；Android 实际呈现频率受设备、刷新率、绘制与主线程负载影响。没有为动画增加模型请求、唤醒锁或逐帧位图生成。

## 验证口径

- 单元测试校验整个举杯周期的双手接触、杯沿与头部嘴部重合、翻页及手机触点、跨状态接触、其他道具持握、写字循环闭合、旧回复清理和刷新预算。
- 原生设备测试检查真实悬浮窗的状态、触摸、系统和应用减少动态效果、隐藏、息屏及恢复；导出四套主题的全状态图。
- 原生绘制回放直接使用 `CompanionPetDrawable`，按实际调度策略保持或更新帧；用于查看动作，不作为真实模型任务已发生的证明。
- CPU 采样采用同一 Pocket S、USB 供电、相同测试方法和 30 秒窗口。CPU 时间不能等同于整机耗电；本轮不据此声称电池续航提升比例。

本机原始日志、画面保存在 `reports/pet-animation-20261106/`。

## 同机性能对比

最终 `final-power-device.log` 的两项测试完整通过。下表来自修改前、修改后各一次相同的 30 秒采样；设备均为 Pocket S，USB 供电，电池温度 31°C。

| 指标 | 修改前 | preview.82 |
| --- | ---: | ---: |
| 可见桌宠的进程 CPU 时间 / 30 秒 | 3,579 ms | 2,768 ms |
| 可见桌宠的进程 PSS | 103,811 KiB | 101,484 KiB |
| 原生单次绘制 P50 | 1,083 μs | 805 μs |
| 原生单次绘制 P95 | 1,264 μs | 1,212 μs |
| 隐藏时进程 CPU 时间 / 30 秒 | 15 ms | 19 ms |
| 息屏时进程 CPU 时间 / 30 秒 | 0 ms | 3 ms |
| 隐藏、息屏时是否排动画帧 | 均否 | 均否 |
| 唤醒后是否恢复动画 | 是 | 是 |

可见状态下该次采样的进程 CPU 时间下降约 22.7%；隐藏与息屏的几毫秒差异不足以解释为回归。CPU 包含整个应用进程而非仅动画；单次短测没有统计置信区间。两次采样电量计均保持 5,695,000 μAh，设备正在供电，因此不报告续航提升比例。中途曾有一次采样被另一轮设备 instrumentation 强制终止，已排除，最终结果仅取完整通过的日志。
