### 首次测量

AYANEO 已安装包的 APK 版本为 0.3.6（44）。首次测量时 USB 充电、电量 100%、电池温度 30.0 °C。一次旧版暖启动 871 ms，Activity 刚启动时进程 PSS 为 162854 KiB。只有三个渲染帧，不足以评价动效流畅度。

工作区基线：TypeScript 和仓库质量门通过。Vitest 有 2 项失败，Node 脚本有 2 项失败，Android 单测有 3 项失败、37 项跳过；ESLint 有 218 项错误，包含非产品目录。回归结果与设备验收分开记录。

### 独立派工与模型联测

桌宠与原生工作台将交办写入同一份原子命令队列。后台收到文件变更后从队列接取，启动时和低频心跳也会补读。SuperAgent 以稳定命令 ID 创建工单，每个 Worker 使用独立会话。默认只读，允许设备操作需按任务选择。运行中的对话与新的交办使用不同的执行路径。

AYANEO 从此前的 0.3.42 运行环境升级到 0.3.47 时，13 个任务文件的合并哈希一致。首次两项交办 4 ms 内落盘并建立两个工单，但都因未配置模型凭据失败。使用用户此前明确提供给 AYANEO 的测试凭据重跑，10 ms 内保存两项真实任务。第一项等待选择颜色时，第二项计算得到 579；回答第一项“蓝色”后两个 Worker 均完成。整轮 47.581 s。测试凭据在本轮结束后恢复原状态。证据位于 `build/ayaneo-live-workers-0347.log`。

### 本地资料与中文语音

分享目标兼容附件和附言，保留系统提供的来源线索与分享链接；本地文件选择器支持多选。图片和文档沿用原件哈希、提取范围与分段引用。音频走 Android 解码器和 Vosk 中文离线模型，保留分段时间戳及原件，单次分析前十分钟。模型仅在转写时加载，识别后释放。此次实测音源是固定中文合成语音；其他语言、方言和不同应用的私有编码仍需分别验证。

SQLite 字符对索引面向中文子串，增量处理旧记录，查询会同时检查待索引记录并复核原文字串。管理页支持正文或文件名搜索；模型工具保留版本检查与引用。AYANEO 隔离测试库 1200 条资料，7 个命中，新旧路径顺序一致，12 次预热查询均值 7.911 ms 和 0.333 ms；编辑及删除后命中同步变化。测试录音识别出“明天下午三点开会”和“请带上蓝色的笔记本”，起始时间为 00:00、00:02，包含识别在内的复测耗时 1.52 s。证据位于 `build/ayaneo-desk-memory-real.log`。设备未安装微信或小红书，尚无两款应用直接分享验收。

### 功能工坊与桌宠

0.3.48 运行环境新增 Harness 创作工具，草稿由 Android 原子保存。应用独立页面运行生成的单文件 HTML/CSS/JS，当前可制作离线交互工具。源码编辑、草稿、启用、停用和恢复分开，已启用功能不随新的草稿改变。升级 0.3.47 → 0.3.48 前后 17 个任务文件合并哈希一致。真机 Harness 已实际调用创作工具生成温度换算器，85.304 s；详见 `build/ayaneo-live-creator-0348.log`。生成通过与表单能否正确运行分别验收。

桌宠改用可复用的身体、眼部与独立手臂图层。尾部按局部网格变形，拖动产生滞后；桌宠可见时按交互状态和节电模式调整更新频率。相同 AYANEO 软件画布、305 px 源图、192 px 目标和 220 个采样帧，原绘制 P50/P95 为 826/880 µs，新绘制为 509/941 µs。此次中位数降低、尾部略升。这项测试不测整机帧率、电池续航或美术质量。

### 动作复审与关节重做

用户看过 7 秒待机实录后指出幅度太小，要求头、鳍、手臂和尾巴能独立运动，并要求待机、接单和工作各有自己的动作。上一版实录保留作对照。新版把接单绑定在队列持久化成功之后，运行姿态读后台台账，等待与收尾使用真实回执。以下记录区分构建结果、实机画面和耗时。

- 角色使用 17 个分层关节与静态纹理权重，左右肩、肘、腕独立。待机有头鳍错拍和两段尾摆，接单敬礼，工作时手腕点任务板，等待时歪头伸手，完成时双手抬起并跳两次。不同状态之间插值 190 ms。
- 第一次实录显示后台回执自动展开聊天窗，遮住了追问和庆祝。已改为不接管输入焦点的可点击提示，用户自己展开时再根据桌宠与键盘位置布局。第二次实录中，桌宠横坐标为 2260..2524，手动打开的聊天窗为 1276..2236，间距 24 px。实机断言角色矩形与对话矩形没有交集。
- 第二次实机任务由真实模型询问颜色，收到“蓝色”后完成。状态依次为待机、接单、工作、追问、继续工作、庆祝和待机；接单约 1.8 s，庆祝约 2.2 s。入口时间戳与工单结果见 `build/ayaneo-live-pet-rig-v2.log`。回执没有自动打开完整聊天。
- `reports/ayaneo-workbench-20261104/ayaneo-pet-task-states.mp4` 长 14.97 s，以真实录屏剪短了两段模型等待时间，字幕位于悬浮窗下方。并排画面为 `reports/ayaneo-workbench-20261104/ayaneo-pet-state-comparison.png`。待机样片此前未通过观感验收，随后用户看过新版实录并明确要求保留此版动作，继续优化其他功能。

### 长期记忆精确检索的完整性

在 620 条较新记录前放一条旧的唯一完整命中，另放一条未确认的同文记录。原机上安装的版本返回 `none`，见 `build/ayaneo-memory-before-precision.log`。修正沿用原字符对索引和原备份结构，单字和双字查询直接在 SQL 中计数、分页。长句先求出各字符对的交集，再按规范化原文核对语序。关联检索仍有独立的候选预算。

### 收尾与工单回执一起提交
