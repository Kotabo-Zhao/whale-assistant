# 鲸鱼助手 0.3.8-preview.77

本版将手机操控状态融入桌宠，并补上主屏操作的持久回执与中断对账。复杂任务实测还发现并修复了中文输入法改写网址的问题。运行环境版本为 `0.3.83-whale-screen-coordinates`。

## 桌宠表达状态

- 移除独立的手机操控状态条。桌宠会从围裙前抬手取出手机，低头点按；观察、等待、暂停、停止与异常各有对应姿势和手机画面。
- 操控期间单击桌宠打开控制菜单，可以暂停、恢复接收新操作或停止；平时仍然单击聊天。暂停和停止立即覆盖其他动画，已撤销的步骤不会因恢复而重放。
- 保留接单、工作、询问、庆祝、触摸和挫折等原有动作。两套主题的浅色、深色共用动作，手机道具和菜单跟随配色。
- 减少动态效果时保留表达当前状态的静态姿势；息屏和不可见时停止动画。等待、暂停等轻动作降至 20 Hz；道具采用矢量绘制，不逐帧创建位图。
- 未常驻开启桌宠时，已授权的手机操作期间临时显示桌宠，结束后收起，不修改常驻开关。仍需既有悬浮窗权限。
- 桌宠和控制菜单的实际区域参与 OCR 来源排除与点击保护，拖动、旋转和收起后更新区域。

## 主屏操作中断恢复

- 单步操作及连续导航在 Android 侧写入 SQLite 执行日志，使用 WAL 与 FULL 同步；记录执行意图、注入边界、观察摘要及桥接回执接收时间。
- 操作编号由宿主会话和工具调用编号生成，同一调用重试只读取记录，不再次注入动作。暂停前的取消票据也持久保存。
- 中断或回执写入失败后保留结果未知；新屏控操作须先通过 `mobile_screen_recover` 重新观察对账。观察过不等于业务成功，不会自动续跑旧步骤。
- 原执行代次不能改写恢复后的记录。日志不可写、损坏或容量耗尽时，在动作前拒绝；点击后的写入失败保留待核实记录，不能静默退化成无日志执行。
- 不保存整张截图、OCR 正文或输入内容；保留摘要、时间、步骤和关联标识。详细记录上限 2,048 条，终态详情按批淘汰，操作编号墓碑上限 65,536 条，容量不足时拒绝新增动作。

这是统一执行事实的第一阶段，覆盖 `mobile_screen_act` 和 `mobile_screen_sequence`。原始 Shell、副屏以及领域、Worker、目标、主动事件和最终用户投递仍未合并为同一事务，不能据此宣称整个 SuperAgent 架构已完成。

## 真实 App 的文本输入

- `mobile_screen_act` 增加文本输入，支持 Unicode 和多行正文；先点击并观察输入框，再选择全选替换或在光标处粘贴。输入不会自动提交。
- Shizuku 通道用系统剪贴板及粘贴按键，避免中文输入法把网址、标点和单词重新组合。该操作替换系统剪贴板，不后台读取旧内容，输入内容保留到下一次复制；系统预览标记为敏感内容。
- 校验目标 App、单次观察、锁屏、取消状态及屏幕尺寸；文本步骤同样进入执行日志。相同文本在相同画面两次操作后无变化时，拦截继续重复输入。
- 输入回执只代表按键注入，最终文本和保存结果仍须从目标 App 核实。部分 App 自定义编辑器不支持系统粘贴时会如实留待观察，不会悄悄改用文件写入。
- App 启动改为解析系统登记的桌面入口并显式启动，再核对前台包名。修复部分 ROM 上 `monkey` 返回零退出码却未打开应用的情况；未到前台时返回明确失败。截图坐标提示统一指向合并观察的主屏工具。
- OCR 返回明确标注物理像素，并去掉供内部诊断的解码尺寸，避免模型重复缩放坐标。有文字的菜单优先按最新文字定位，减少弹窗与键盘移动后的旧坐标误点。
- 动作后的观察增加短时画面稳定取样：避开桌宠及系统栏，先比较少量像素，再只对最后一帧做 OCR。菜单或键盘仍在移动时不发操作租约，要求重新观察，避免把动画中间帧当成可点击位置。取样最多四帧，有时间预算；不宣称画面稳定就代表业务成功。
