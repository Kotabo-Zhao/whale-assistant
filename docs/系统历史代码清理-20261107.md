# Whale Assistant 系统历史代码清理

清理以 `whale-assistant` 提交 `99c0e342` 为基线。核查范围包括 React 工作台、Android 服务和桌宠、Capacitor 通信、运行环境插件、构建发布脚本及 APK 资源。前端从 `src/main.tsx` 跟踪静态导入、动态导入和 Web Worker 入口。Android 侧同时检查清单、XML、资源名、反射调用和设备测试。构建脚本按调用方、输入摘要和目标版本判定用途。

| 范围 | 清理结果 | 核对依据 |
| --- | --- | --- |

| Android | 移除旧会话导航壳、独立工具浮窗实现、老头像采样器、未使用的回复收集器、通知枚举、次日索引延迟函数和旧理解队列处理器 | 会话使用 `activity_harness`，桌宠工具已切换到 `PetInlineTool`。理解队列的事务测试改为直接调用仍在使用的领取和提交接口 |

## 经核对保留的实现

- 将 Web Worker 的 URL 入口计入后，88 个前端生产模块中有 87 个可从主入口到达。`SuperagentSettings.tsx` 是余下的模块。它保存 GitHub 和飞书的授权设置，并处理撤权与并发修改冲突，是仓库中唯一的前端编辑实现。本次保留组件及其独立测试，它当前没有应用导航入口。
- Android 原生 `CompanionWorkerPanel` 仍为桌宠提供任务计数和派工。其旧管理对话框还有设备用例直接构造，验证权限恢复、任务分页等行为。本次保留此模块及底层工单、执行台账和恢复接口。
- 启动验证缓存、旧数据迁移、删除内容抑制记录、后台权限复核、审核插件兼容钩子与运行包摘要白名单都有独立职责。它们不能按页面有无入口判断是否可删除。
