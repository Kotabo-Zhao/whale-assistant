# 鲸鱼助手 0.3.8-preview.74

本版缩短主屏观察、截图和动作回看链路，保留 preview.73 的 App / 桌宠动效、竖屏高度与工单恢复功能。

## 屏幕控制提速

- 本地 OCR 使用按需原始帧管道，去掉截图 PNG 编码、终端 Base64 与二次解码；区域识别先裁剪、再按需采样，坐标映射回原始物理像素。
- 视觉截图使用最长边 1600 像素、82 品质 JPEG，返回物理屏幕尺寸和准确换算比例；旧 PNG 命令保留兼容路径。
- 新增 mobile_screen_act：点击、滑动或返回后，一次返回动作注入回执和新观察。无障碍服务存在时保留其白名单、确认和敏感窗口校验；未启用时，使用用户已开启的 AI Shell / Shizuku 常驻进程注入。
- 最新观察编号只使用一次，有效期 15 秒；其他设备操作、暂停 / 停止、尺寸变化后旧编号失效。编号不是授权，也不保证外部应用在思考期间未发生变化。
- 暂停与停止能撤销在途手势，用 CANCEL 清理已按下的触点；自动坐标动作不能触碰控制状态条。输入结果不确定时不自动换通道或重放。
- 设备桥按请求数据就绪派发，空闲 HTTP 连接不占解析线程；工单回写与前台控制分开排队，避免后台挤占屏控。暂停前已排队的动作也会撤销。
- 原生节点可用时继续优先使用节点。只有需要图像理解时才传截图，减少模型回合与图像上传量。

观察约缩短 68%，截图约缩短 62%、体积约减少 75%。Shell 点击列含桥调用到控件响应；常驻注入列只计服务内部注入，不直接计算这两项的提速比例。数据是本机局部控制链路，不包含云端模型推理、网络和目标 App 的业务加载时间；不能据此声称整个任务快了相同比例。

冷启动的 4 项原始帧、真实模型输入与异常回归通过：实际点击 12 次（其中真实模型 2 次），重复旧编号 / 暂停后旧指令被拒绝，暂停和停止在途滑动均收到 CANCEL、没有延迟 UP / 点击，控制条防误点通过。

24 条空闲 HTTP 连接下观察耗时 320 ms，后台回写队列占满时为 193 ms；真实模型使用新工具完成两次点击并回看，整轮 10.661 秒，包含模型和网络等待。

真实竖屏 1080×2400 下另有 4 项测试通过，覆盖完整观察、坐标反算、真实输入与可见暂停 / 停止；已查看真实 JPEG，测试后恢复设备显示设置。
