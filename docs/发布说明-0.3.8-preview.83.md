# 鲸鱼助手 0.3.8-preview.83

日常只和小鲸对话：主人档案、秘书事项及后台任务在内部推进，重要结果与需要用户决定的事由桌宠统一转述。App 与桌宠共用同一份资料和近况。

- 移除 App 和桌宠新增的档案、秘书表单入口；原有记忆授权、查看和遗忘能力保留。
- 用户说出称呼、偏好、身份时自动整理相应信息；自然交办、改期或说「做完了」时更新同一事项。只有信息不明确或需要决定时才询问。
- 每轮自动加载当前确认档案，App 与桌宠共用；纠正优先于旧对话，遗忘抑制旧内容重新生成。
- 保留事项去重、版本检查、备份恢复，以及改期、完成、取消后旧提醒失效的闭环。
- 正常回复不播报字段名、版本号等内部细节；不会要求用户到设置填写档案。
- Worker 原始回执不再弹出，也不再作为用户任务面板展示；App 任务页默认“小鲸近况”，桌宠“聊聊近况”展示同一份自然总结。简短追答继续原任务，不重复派发。内部执行会话不再挤占历史列表，长总结的继续按钮独立成行。
- 运行环境、设备与诊断入口收进折叠的“高级设置”；概览不再堆叠内部数据计数。真实权限请求、必要追问和停止入口仍可用。
- 首页移除重复的底层自动化任务与连接诊断卡；需要检查时从高级设备设置查看，正常交办由小鲸统一回应。
- 旧版内部协调进度保留作诊断，不混入新的“小鲸近况”或对话背景。
- 记录每件事是否已向用户汇报；默认查询省略已送达结果正文，避免回答一个新问题时又附带旧结果。断线、重试和重启不会误判为已经告知；任务有新结果后重新进入待汇报状态。
- 后台汇报只描述有变化的事项；修复桌宠把中间草稿拼进最终回复的问题。取消已核验版本评分插件对前台的自动阻塞与强制重写，避免它在缺少上下文时改错称呼、重复催交任务。任务结果仍通过实际回执和完成条件核验。
- 移除自动生成的 Token、调用次数、累计时长配额及相应模型工具参数；旧任务限额不再阻止继续执行。原生模型调用不再默认指定采样温度。
- 资源调度依据实际负载；普通发热不会暂停任务。系统接近过热关机、用户停止、真实权限和故障恢复仍按实际状态处理。
- 运行环境更新至 `0.3.92-whale-pet-front`，兼容旧环境中缺少 `AbortSignal.any` 的 Node 版本。

本版合并保留 `.82` 冻结的动画代码。用户已对该动画观感提出异议，独立动作重绘仍在另一个任务进行；本版不将其标为最终视觉验收通过。

这是用于实机验收的调试签名包。测试过程、版本和范围见[主人档案与秘书验收](PocketS主人档案与秘书验收-20261106.md)。
