# 鲸鱼助手 0.3.8-preview.94

这是重构第一阶段的内部预览，不是对外正式版。包名仍是 `io.deepseekharness.mobile`，签名配置没有改动。

对话页只保留进入对话的主操作，以及资料、任务、工具三条去处。底部导航改为「对话 / 我的」。设置首页默认展开「日常」，设备控制和运行环境仍收在「高级设置」里。GitHub 与飞书渠道放在诊断页的折叠面板中，本阶段没有做跨渠道闭环。

尚未单独打开过的「桌宠使用长期记忆」和「对话检索本地资料」默认视为开启，设置里仍可关闭。已经保存为关闭的选择保持关闭。通知正文、日历、写入资料库和完全权限仍需单独允许。事项查询按来源过滤：秘书事项跟随长期记忆，资料关联事项跟随资料检索，通知事项仍要单独授权；未授权来源会在结果里标明，而不是把整个事项列表挡住。

本环境没有 AYANEO 或可启动的 arm64 模拟器读数。调试包可以编出，但不含 Ubuntu rootfs，不能据此声称对话服务已经在设备上跑通。
