# 鲸鱼助手 0.3.8-preview.87

工作台、资料、任务、工具、设置和会话管理现在使用统一的内容边距。切换页面时标题对齐，窄屏上的会话操作可以换行。设置搜索占满一行，高级分类开关位于标题右侧。

设置子页的返回按钮显示父页名称。从无障碍、副屏或自动参数返回自动化设置，从日志、设备能力或反馈返回诊断与日志。后台页的桌宠说明使用完整文本列，副屏页共用上层标题。角色管理、资料阅读和插件工作台沿用同一套页面排版。

原生助手偏好和功能工坊按窗口宽度与系统字号选择卡片列数。打开这两个全屏界面时，闲置桌宠会收起，子菜单可以直接点按；浮动工具仍能与桌宠同时使用。资料搜索的结果列表会给输入法和关闭按钮留出空间。窄屏打开资料时，阅读层贴合可用窗口。

AYANEO Pocket S 已保留数据升级到版本码 132。横屏与 360dp 竖向窗口的实测范围、字号及浏览器检查见[排版验收记录](./App页面与子菜单排版验收-20261107.md)。
