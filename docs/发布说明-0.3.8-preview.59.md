# 鲸鱼助手 0.3.8-preview.59

- 在「我的 → 助手偏好 → 记忆与资料」开启「结合最近对话和资料主动跟进」和资料检索。桌宠在解锁、空闲时匹配近 7 天的主对话或桌宠对话与资料库，找到值得跟进的问题后主动搭话。
- 单次最多使用同一会话的四条短摘录和一段相关资料。模型可以保持安静，已判断过的同一组内容会去重。可在全部助手偏好中设置每天或每周最多判断一次。
- 沿用运行环境 0.3.60-whale-knowledge-write，本次更新只需安装新版应用。

已在 Pocket S 上验证：真实主对话留下未定会场，新增资料后，系统桌宠气泡主动提出布展时间，点开可见同一个问题。另一组已办结事项由真实模型判断保持安静。
