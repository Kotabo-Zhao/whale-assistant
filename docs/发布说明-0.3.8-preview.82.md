# 鲸鱼助手 0.3.8-preview.82

后续状态：用户已指出本版动画异常，并要求每个动作独立绘制；下面记录的是本版实现与技术检查，不能视为最终视觉验收。独立重绘在后续版本继续。

桌宠的道具从单独挂图改为实际持握动作，并梳理表情、状态切换和后台刷新。

本次合并同时包含 preview.81 的主人档案和秘书事项闭环。后续 `.83` 已根据用户要求移除专用表单入口，转为自然对话自主维护；详细记录见[主人档案与秘书验收](PocketS主人档案与秘书验收-20261106.md)。

- 杯子加入举杯、喝水与放回；书本加入双手持握、翻页和收手；手机加入持握、手指接触屏幕、暂停举手与收回。其他手持道具统一抓握坐标和朝向。
- 修复闭眼表情被覆盖、眨眼贴图重影、长期保持张嘴、旧回复抢占新思考等问题。
- 降低安静待机刷新；交互和眨眼时提高刷新；系统与应用减少动态效果直接停帧，息屏、隐藏和窗口移除停止排帧，恢复从当前姿态衔接。
- 两套风格的浅色、深色继续共用角色与动作，业务状态和控制权限保持原有边界。

Pocket S 已保留数据升级并通过触摸、状态切换、系统动画设置、隐藏和息屏恢复测试。同机 30 秒可见状态采样的进程 CPU 时间从 3,579 ms 降至 2,768 ms，约下降 22.7%；隐藏和息屏均不排动画帧。Android 单元测试 1,852 项通过、37 项跳过、零失败。本地 APK 为兼容当前测试安装的调试签名包，尚非正式团队签名发行包；全仓 Lint 另有 7 项非本轮修改文件中的已有错误。

详细问题清单、动作约束、设备记录和验证限制见[桌宠骨骼交互与节能优化](桌宠骨骼交互与节能优化-20261106.md)。CPU 采样不代表整机续航测量，视觉效果仍需结合实际使用反馈。
