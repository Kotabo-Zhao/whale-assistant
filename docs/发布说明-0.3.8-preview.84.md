# 鲸鱼助手 0.3.8-preview.84

桌宠动作重制：17 个业务状态和独立喝水动作改用各自绘制的完整角色帧，移除公共骨架变形、眼嘴贴片和手持道具层。阅读会翻页，书写采用坐姿，喝水有抬杯与放低，手机动作包含指尖接触和离开；手、道具、袖口和表情一起绘制。

动画按每帧停留时长更新，长停留期间不持续刷新。后台按需解码，缓存最多 3 张图集、最多一张在途解码；快速状态变化合并为最新动作。熄屏、锁屏、宿主遮挡和减少动态时停止动画回调。

用户指出首版样片卡顿后，12 组主要动作补画为各 16 帧，移动阶段缩短到约 80 ms；静止姿态保留自然停顿。省电模式改为待机静态，不再将动作段限制到约 5 FPS。

暂停、结束和异常不再反复播放进入手势；接单后的回复、真实设备控制优先级和拖动反馈保留。重载桌宠尺寸时保留正在播放的接单或回复。

原画、生成及修订提示词、打包脚本和离线播放器均保留。preview.82 的旧骨架视觉方案已被用户指出异常，本版使用新的实现；测试通过不能替代实机观感验收。耗电改动属于减少唤醒与绘制开销，尚不宣称电池续航提升比例。

已合入 preview.83 的主人档案、秘书闭环和前台统一转述成果，保留 runtime .92。实机还修复了系统动画比例监听读取旧缓存时不能及时停播/恢复的问题。

Pocket S 已保数据升级至 .84 / 129，安装包与内置运行时哈希核对一致。动画设备回归 12 项、性能及熄屏检查 3 项通过；可见待机 30 秒进程 CPU 548 ms，隐藏与熄屏各 1 ms，三图集缓存 18.75 MiB。测试不等同于用户视觉验收或离电续航结论。详细记录见《桌宠独立动作重制-20261106》与《PocketS桌宠独立动作验收-20261106.json》。
