# 桌宠插值与收尾修订 · 2026-11-07

用户在 preview.84 后指出动作结束回待机仍有跳变，并明确要求用插值提高帧率。本版同时处理画面密度与收尾衔接；.84 的包、测试记录和素材预览保留为历史检查点，不把它们当作新要求的完成证据。

## 实现

- 18 组基础动作仍各自拥有完整角色原画；另外为 17 个非待机动作分别生成和修订 16 格收尾原画。没有公共骨架、悬浮道具或独立眼嘴层。图像为原生 image_gen 生成美术，不冒称人工逐帧绘制。
- `PetPlayback` 将业务状态与视觉收尾分开：回待机时沿原帧序完成手势，缩短尚未结束的长静止等待，然后播放专属收尾。新消息、控机或拖动立即中断收尾。收尾完成后待机视觉从第 0 帧开始，偶尔饮水仍按原来的 24 秒计划安排。
- 17 组收尾的首帧与原动作末帧、末帧与待机首帧均逐像素相同。原版 240 张动作关键帧与 .84 Git 检查点逐像素一致。
- 双向 DIS 光流在制作端离线运行。使用透明预乘、位移场平滑和遮挡区域单侧采样，修正初稿的翻页双轮廓；不在 Android 安装包中引入 OpenCV 或实时光流计算。
- 35 张图集共有 1024 格：512 个关键帧格、488 个真正的中间帧、24 个不播放的重复填充格。主要动作移动段 40 ms（约 25 帧/秒），触摸和收尾移动段 30 ms（约 33 帧/秒）。长静止姿态不固定刷新，视频容器 FPS 不作为运动帧率。
- 透明行缝切片避免坐姿起身稿的相邻画面串入；整帧配准修正画布漂移。阅读多尾巴、庆祝背景、书写排列的修订稿与提示词均有来源记录。
- 图集按实际显示像素解码，保持 ARGB 透明度。缓存最多 3 张，字节预算按“待机 + 两张大动作图集”的实际尺寸计算，最高 32 MiB；264 像素时为 22,302,720 字节（21.27 MiB），另可有一张在途解码及解码器临时内存。隐藏时不排队解码或刷新。

## 验证与边界

制作检查已查看所有收尾的连续关键姿态、位移最大的 12 对插值画面、书页交叠与透明轮廓。离线播放器检查 35 组 / 1024 格的加载、逐帧、暂停续播；无浏览器脚本错误。像素与控制检查证明接线与素材一致，不能单独证明自然度。

代码检查：TypeScript、ESLint、前端 94 文件 / 1156 项测试、脚本 507 项通过（4 跳过）、4 项门禁通过。Android 235 套件 / 1892 项中 1855 通过、37 跳过、零失败。未重跑完整 Android Lint，不将此前已知无关 Lint 问题写成通过。

实机使用 Pocket S（0031BRHA01029239），保数据覆盖安装；模拟业务状态用于动画检查，不声称录屏中的持机/书写动作就是实际 Worker 任务。省电模式回归通过注入服务状态验证播放策略，不等于拔线后的系统省电续航实验。

最终安装包哈希、实机回归、可见/隐藏/熄屏测量及录屏证据记录在同目录 JSON 验收文件。USB 供电短样本只支持 CPU、内存、停刷行为对比；没有离电长时续航或用户视觉验收。
