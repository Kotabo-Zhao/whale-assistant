# 预览五十二：桌宠等待恢复与记忆授权入口

用户反馈荣耀 Magic6 在 DeepSeek 无响应时桌宠长时间不可恢复，以及 Agent 提示无法操作本地记忆。本轮修复代码中可确认的等待和授权入口缺口；尚未取得荣耀当次故障日志，不能将模拟故障测试等同于复现原始事件。

## 回复等待与恢复

- 意图分类请求总时限 30 秒，直接回复请求总时限 120 秒，单次前台回复操作总时限 180 秒。总时限覆盖持续保活流，避免仅依靠每次读取超时而无限等待。
- 桌宠在等待期间显示“结束等待”；关闭再打开窗口后仍可使用。取消会中断前台执行线程、撤销模型请求或断开本机跟随连接，不取消已提交的后台任务。
- 失败保留原消息及原请求标识，可重试原请求或开启新话题。复用执行线程前清理中断状态，避免下一次消息立即失败。
- 完成回复进入本地保存后，迟到的取消不会把已保存回复误报为失败，避免重复提交用户操作。
- 使用共享 HTTP 客户端与按请求生命周期创建的截止定时器，不增加空闲轮询。尚无本版本长期耗电测量结果。

## 本地记忆

- 在“我的 → 助手偏好 → 记忆与资料”补齐“允许桌宠访问长期记忆”，修复原生已有独立权限、网页设置却缺少对应入口的问题。长期记忆总开关和桌宠授权分别生效，不自动更改现有授权。
- 开启时说明相关内容可能发送给当前模型服务；拒绝访问时返回准确的设置指引。能力查询明确列出搜索、保存、修改、删除工具。
- 路由提示明确将记忆保存、纠正和删除交给主会话执行。只读 Worker 的工具权限没有放宽；本机记忆工具不依赖 Root 或 Shizuku。
- 默认保存仍产生待确认候选，未擅自开启自动批准。已确认记忆支持带版本的修正，撤销桌宠授权后立即拒绝后续操作。

## 验证及边界

- 前端 91 文件 / 1148 项通过，类型、静态检查、质量门禁通过；脚本 450 项通过、4 项跳过。
- Android 全套单元测试及应用、设备测试包构建通过。新增单元测试覆盖持续保活总超时、无响应头取消、执行线程复用、跟随等待截止以及回复保存与取消的竞态。
- AYANEO 最终包 6 项设备测试于 0.706 秒通过：真实悬浮窗在本地 HTTP 服务不响应时关闭重开、结束等待、保留消息、开启新话题及再次回复；隔离数据库中的记忆授权、保存、确认、查询、修改、删除和撤权；流式结束标记回归。使用隔离夹具，没有读取或修改用户记忆，也未发送真实模型请求。
