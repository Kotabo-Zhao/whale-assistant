# 预览五十：资料投放、检索与阅读流程

资料页将本地文件、文字/链接与其他 App 的投放方式聚合为同一入口区，保留系统分享、选中文字、桌宠拖入和快捷设置收藏的现有通路。系统分享仍直接保存并返回来源应用，不增加确认步骤。搜索独立展示，备份、筛选与批量管理保留在次级入口。

列表显示当前已加载条数（不是整个资料库总数），搜索结果增加有界正文摘要与字面命中高亮；无文件名的长文本也能显示命中附近的内容。空结果可清除搜索或筛选，最近投放首次读取期间不再误显示空库。

正文与资料详情共用阅读层：简约/可爱和明/暗主题统一，关闭入口固定在顶端，录音时间标记保留，打开时锁定背景滚动，键盘焦点循环，Escape 返回并恢复原入口焦点。没有新增轮询、常驻动画或后台服务。
