# 鲸鱼助手 0.3.8-preview.76

在 preview.75 连续屏控基础上，进一步减少模型为核验页面而追加的观察、截图和重复导航。

## 本版变化

- 竖屏控制状态条避开顶部双行标签，横竖屏切换后重新计算位置和宽度，保留可见的暂停 / 停止与防误点区域。

- 当前模型支持图像且没有原生控件树时，连续导航将最终截图与逐步回执一起返回。截图采集仍在同一次设备执行锁内，前后核实目标 App；新截图拥有新的观察编号，旧文字观察编号失效。
- OCR 疑似误读一个字符时，选择该位置的局部像素重识别。近似匹配只用于读屏区域选择，真正点击仍要求精确文字；目标在转场后出现也能触发这次重识别。
- 读取标签下方真实的局部高对比指示线，作为视觉选择提示交给模型，减少依赖旧版 App 外观印象造成的误判。该提示不伪装成无障碍的 selected 状态，也不证明业务成功。
- 收紧已完成导航后的核验提示：不得为验证而重复切换标签，最多补一次只读观察；仍不确定则说明不确定，不转入循环截图和 Shell 像素分析。这是模型路由约束，不等于对所有模型输出提供确定性时延保证。
- 回答评分兼容同时包含文字和图像的工具回执，保留原有质量门槛与重试配置。附件保存失败仍返回动作回执和明确错误，不重放已执行动作。

本版继续包含 .75 的有限文字导航、常驻前台应用查询、控制浮层识别、暂停 / 取消、异常停止与无重复执行守卫，也包含先前的两套主题、动效、竖屏桌宠高度和工单容灾功能。

## 实测与架构分析

测试方法、全部有效基线与保留的失败 / 慢样本见[真实 App 多步屏控实测](真实App多步屏控实测-20261106.md)。早期 .76 曾出现模型在动作完成后反复怀疑界面、整轮 112.511 秒并多次切换标签的失败；此问题没有被计作通过，也没有从记录中删除，随后补充视觉指示线与核验约束。

对照最新公开 DeepSeek SuperAgent 的[架构缺口报告](SuperAgent架构缺口-连续高效主动持久-20261106.md)已完成。下一阶段建议集中在统一执行日志与结果对账、主会话最小上下文、目标协调、主动事项生命周期和系统级长期验收；这些建议尚未开发。
