### SuperAgent 任务记录适配

对照原型 `src/executor/dsh.ts` 与 `src/core/assignments.ts`：原型每个 Ticket 有长期执行 Session，Assignment 记录输入投递、进入会话与阶段报告；其 Worker 不等同于 Harness 内置 subagent API。当前按手机场景沿用现有轻量任务记录，新增原始请求、追问回答和继续说明的持久输入记录，区分待投递、投递中、已投递、已进入会话及状态未知；保存每轮回执和工具调用统计，任务卡显示历史。运行中断不自动重放手机操作，投递中断时标为未知并需确认。旧任务只记录可知内容，不伪造历史。保留无固定并发上限、屏幕互斥和会话权限。

该阶段不等于完整移植原型的 Trigger/Eval/Mandate、跨渠道、数据库 outbox 和自动重启恢复；旧有汇总准确性与响应速度还需真实任务复验；本次设备验收结果见下文。


### SuperAgent 后续输入适配

已继续接入任务后续信息：运行中收到的追加输入持久化排队，当前轮结束后按顺序进入同一 Worker 会话；已完成任务可按用户要求重新加入信息继续。回执保留各轮状态，取消时未投递追加信息标为取消；命令 ID 用于避免控制消息重复入队。任务卡提供追加入口。此实现不等于原项目完整跨来源事件和工单授权模型；本次设备验收结果见下文。
