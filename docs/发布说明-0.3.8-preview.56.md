# 0.3.8-preview.56 · 桌宠记忆与工具浮窗

暂停自动整理后，可以在桌宠对话里说「请记住……」。桌宠沿用长期记忆和桌宠访问授权。开启「自动记住对话中的偏好」时直接保存，关闭时生成待确认候选。通知、使用习惯、共享资料和后台理解继续遵守自动整理设置。对话写入仍检查已删除文本的摘要和相似内容签名。

打开桌宠菜单或桌宠对话中的「我的工具」，点已启用的创作工具即可在当前应用上方操作。拖动标题可以移动窗口，「收起」保留输入与结果，「展开」继续操作。关闭桌宠对话后工具可以继续运行。切换版本或停用工具会关闭旧窗口，「详情」可进入原有结果操作页。

工具浮窗使用已发布的本地 HTML 界面和独立 WebView，保留原有网络、文件和原生桥限制。独立安装的原生 APK 从原生入口打开。Android 的受保护页面可以隐藏第三方悬浮窗。
