# 鲸鱼助手 0.3.8-preview.86

修复桌宠窗口短暂不可见后，动画回调被清除、重新可见却无法恢复的问题。旧版只在挂载、屏幕广播和设置变化时重新创建回调；普通回复、拖动和任务变化只能唤醒已有回调，因此可能出现角色仍显示、动作一直不更新的现象。

桌宠现在监听窗口与视图的实际可见性变化，在首次布局和重新显示后恢复动画；业务事件发现回调缺失时也会重新创建，并保留刚收到的回复或其他动作。布局变化不会重置正在播放的动作。隐藏、锁屏、息屏与减少动态继续停止逐帧刷新，省电静止待机不增加定时轮询。

增加只含动画状态的服务诊断：可见性、动画开关、回调是否排队、已推进帧数、最近推进间隔和当前动作。可用这些信息区分正常静止、省电、窗口隐藏与调度异常，不记录聊天或凭据。

版本为 .86 / 131。沿用 .85 的全部独立动作、独立收尾与离线插值图集，内置运行环境仍为 .92。具体复现、真机验证与限制见《桌宠停帧恢复修复-20261107》。
